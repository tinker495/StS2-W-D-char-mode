# Coding Standards Index

These conventions apply to every mod character and shared implementation. Open only the topics needed by the change; character-specific facts come from that owner's design and visual guides.

| Change | Convention |
|---|---|
| Character-owned types, paths, files or model renames | [Character naming and layout](docs/conventions/characters/naming.md) |
| Gameplay, commands, models, UI, localization or resource extensions | [Native StS2 integration](docs/conventions/native/features.md) |
| Descriptions that reference concrete cards | [Native card previews](docs/conventions/ui/card-previews.md) |
| Character documentation or artwork records | [Topic-based character guides](docs/conventions/documentation/character-guides.md) |
| Architectural review | [Architecture review criteria](docs/conventions/review/architecture.md) |

Existing automated checks own mechanical validation. These documents do not authorize changes to tests or acceptance criteria; [AGENTS.md](AGENTS.md#test-ownership-and-change-authority) governs execution authority. Spec reviews also follow [domain guidance](docs/agents/domain.md#spec-review).
