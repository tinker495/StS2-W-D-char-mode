# 캐릭터 2 컨셉 초안

사용자가 제시한 초기 구상을 정리한 문서다. 테마 방향을 공유하기 위한 초안이며, 미확정 사항을 구현 요구사항으로 간주하지 않는다. 이름과 수치, 세부 동작은 이후 설계 대화에서 구체화한다.

## 기본 유물

**윌드**: 모든 타격 카드를 저주로도 취급하고 보존한다.

**강화 효과**: 모든 공격 카드를 저주로도 취급하고 보존한다. 강화 효과를 얻는 방식은 미정이다.

- '타격 카드'는 기본 타격만이 아니라 이름에 '타격'이 붙은 모든 카드를 뜻한다.
- 윌드의 영향을 받은 카드는 기존 공격 카드의 성질과 사용 가능 여부를 유지하면서, 저주 관련 효과에도 포함된다. 공격 시너지와 저주 시너지를 모두 받는다.
- 재편으로 변형할 때는 원래 카드 타입을 기준으로 분류한다. 윌드로 저주 취급을 받는 공격 카드도 공격용 토큰으로 변형한다.

## 주요 컨셉

| 테마 | 초기 구상 |
|---|---|
| 자가 상태이상 | 스스로에게 디버프를 거는 대신 강력한 효과를 얻거나, 자신에게 걸린 디버프를 활용한다. 상태이상 카드 생성 중심의 테마는 아니다. |
| 공격 카드 시너지 | Ironclad의 공격 카드 관련 시너지를 일부 공유하고, 캐릭터 고유의 시너지를 추가한다. |
| 광란 | 손에 있을 때 바로 왼쪽 또는 오른쪽에 있는 카드를 사용하면 그 뒤에 자동으로 사용된다. 카드 유형은 조건으로 삼지 않는다. 에너지가 부족하거나 없어도 사용되며, 에너지는 0 미만으로 내려가지 않는다. |
| 저주 | 전투 중 일시적으로 저주 카드를 생성하거나 저주와 연계되는 효과를 활용한다. |
| 전략 | 카드 수에 따른 이점과 원하는 카드 탐색을 다루는 테마다. 어떤 카드의 수를 참조하는지는 각 카드에 명시하며, 공통 키워드나 하나의 계산 규칙으로 통일하지 않는다. |

덱이나 손에 생성하는 방해 카드는 주로 저주 카드로 설계한다. 자가 디버프와 저주 카드 생성은 서로 다른 효과로 구분한다.

## 광란의 공통 규칙

- 자동 사용도 정상 비용을 지불하되, 비용보다 에너지가 적으면 남은 에너지만 소비한다.
- 예를 들어 2코스트 광란 카드가 에너지 1에서 발동하면 에너지 1을 소비하고 정상 사용된다. 에너지 0에서도 자동 사용되며, 에너지는 음수가 되지 않는다.
- 광란으로 자동 사용된 카드도 인접한 다른 광란 카드를 발동시킨다.
- 인접 판정은 사용한 카드가 손을 떠나기 직전의 배치를 기준으로 한다. 카드가 빠진 뒤 새로 이웃이 된 카드는 그 사용에 반응하지 않는다.
- 한 번의 카드 사용으로 양옆의 광란이 모두 발동하면 왼쪽 카드부터 오른쪽 카드 순서로 처리한다.
- 먼저 발동한 카드부터 처리하고 후속 연쇄는 뒤에 이어 붙인다. 양옆 A·B가 발동하고 A가 C를 발동시키면 A → B → C 순서다.
- 자동 공격은 발동을 유발한 카드의 적 대상을 이어받는다. 유발 카드에 적 대상이 없거나 그 적이 이미 죽었다면 무작위 적을 대상으로 한다.
- 이미 자동 사용을 기다리는 카드는 다른 카드에 반응해도 중복으로 예약하지 않는다. 사용 후 다시 손으로 돌아온 카드의 재발동을 금지하는 규칙은 아니다.
- 사용 대기 중인 카드가 손을 떠났거나 소멸·재편됐거나, 에너지 이외의 사용 조건 때문에 사용할 수 없게 되면 그 카드의 예약만 취소한다. 나머지 예약은 계속 처리한다. 에너지 부족은 자동 사용을 막지 않는다.

## 서브 컨셉

| 테마 | 초기 구상 |
|---|---|
| 재편 | 기본적으로 손의 카드 하나를 선택해 해당 전투 동안 공격·스킬·파워·그 외의 네 분류에 맞는 특정 토큰 카드로 변형한다. 다른 더미를 대상으로 하는 카드는 별도로 명시한다. 영구 덱은 유지하며, 토큰 네 종류의 효과는 미정이다. |
| 소멸 | 카드를 소멸시켜 저주 등의 페널티를 회피하고 덱을 정제하며 순환을 보조한다. |
| 격전 | 카드 효과 실행 직전에 자신 또는 살아 있는 적 하나라도 최대 HP의 절반 이하이면 추가 효과를 얻는다. 해당 카드의 피해로 조건을 충족해도 뒤늦게 발동하지 않는다. |
| 불실 | 소멸하거나 변화되면 그 카드의 덱 원본을 기준으로 복사본을 손에 추가한다. 원본의 강화·인챈트만 반영하며, 전투 중 비용 변경이나 누적 수치 등은 복사하지 않는다. |
| 망령 | 1코스트 저주 토큰 카드다. 휘발성·소멸을 가지며, 소멸하면 카드 한 장을 뽑는다. 별도 사용 효과는 없으며, 사용하면 소멸하면서 한 장을 뽑는다. 휘발성으로 소멸해도 같은 드로우 효과가 발동한다. |

## 불실의 복사 기준

- 변화 후의 토큰이 아니라 변화 전 카드의 덱 원본을 기준으로 한다. 소멸도 해당 카드의 덱 원본을 기준으로 한다.
- 원본에 있는 강화·인챈트를 반영하고, 원본에 없는 전투 중 일시적 강화·인챈트나 비용 변경·누적 수치는 가져오지 않는다.
- 이 규칙은 앞서 검토했던 '소멸 직전·변화 전 전투 상태를 그대로 복사'하는 안을 대체한다.

## 이후 카드 설계에서 정할 사항

- 재편으로 생성하는 토큰 네 종류의 비용·효과는 세부 카드와 함께 정한다.
- 영구 덱에 원본이 없는 전투 중 생성 카드에 불실을 부여하는 경우의 기준은 해당 조합을 설계할 때 정한다.
