# 정록 용, 아셀리게 — 1막 고대의 존재

기준: [카드 기획 시트의 ‘고대’ 탭](https://docs.google.com/spreadsheets/d/1rwlbeGbN32cwy-rOZWJzCIR_Rhyx5rmiezInGhioEq0/edit). 시트의 A–E열은 대화, F–I열은 유물 목록이며 같은 행에 있다는 이유로 두 항목을 연결하지 않는다.

리소스 경로는 [에셋 문서](/docs/characters/aselige/aselige-assets.md), 로컬 설치 범위는 [공통 배포 기록](/docs/deployment-status.md)에서 관리한다.

## 확정한 조우 규칙

- 고대의 전체 표시 이름은 **정록 용, 아셀리게**이다. 한국어 `STS2WD-ASELIGE.title`에 전체 문자열을 저장해 이름만 읽는 화면에서도 호칭이 빠지지 않도록 한다. `.epithet`은 중복 표시를 피하도록 비워 두며, 영문 표시는 `Verdant Dragon, Aselige`로 둔다. 고대 모델은 이 이름으로 등록되어 있다.

- 파티에 모드 캐릭터가 한 명이라도 있으면 1막 시작 고대의 존재를 아셀리게로 대체한다. 혼합 멀티플레이의 기본 캐릭터도 아셀리게를 만난다.
- 기본 캐릭터만 있는 런에서는 니오우를 유지한다. 2막 이후의 고대의 존재는 이 조건으로 교체하지 않는다.
- 모드 캐릭터 판정은 `Realta`, `Althea`, `Mercurius`, `CharacterFour`(Erenil) 타입을 사용한다. 메르쿠리우스의 저장 ID 및 이름 정책은 [해당 설계](/docs/characters/mercurius/mercurius.md)를 따른다.
- 일반(비-블리츠, 모디파이어 미적용) 런에서는 각 플레이어가 아래 세 묶음에서 하나씩 선택지를 받는다. 포용의 피리의 자격은 해당 플레이어에게 적용하며, 같은 파티의 다른 캐릭터에게 전파하지 않는다.
- 블리츠 모드에서는 모드 캐릭터 파티가 여전히 아셀리게와 기존 대화를 유지해 조우하되, 유물 3종 대신 원작 니오우와 동일한 단일 블리츠 선택지(제목 **정록의 인도** / `Verdant Guidance`, 설명 `카드 3장을 선택해 덱에 추가합니다.`)를 제시해 10장 중 3장 카드 선택 보상을 지급한다. 이어지는 모디파이어 선택지가 없으면 `아셀리게의 인도에 따라 여정을 준비했습니다.`(`Guided by Aselige, you prepare for the journey ahead.`)로 종료한다.
- 커스텀·데일리 런에서 모디파이어가 하나라도 활성화된 경우(블리츠 직후 및 비-블리츠 모두) 아셀리게 유물 3종을 제시하지 않고 원작 니오우와 동일하게 시작 선택지를 제공하는 모디파이어만 순차 실행한다. 비-블리츠에서 시작 선택지가 없는 모디파이어만 켜진 경우 유물 선택 없이 완료 상태로 진입한다.
- ‘깊은 숨’ 재활성화 및 ‘작은 새싹’ 강화의 **휴식**은 휴식 장소에서 **체력 회복을 선택했을 때**이다. 단순 입장이나 제련은 포함하지 않는다.
- ‘정록 용의 강림’은 연계 캐릭터가 확정될 때까지 효과 없는 더미 카드로 둔다. 비용 0 스킬이며, 효과·강화는 없다.

빛나는 잎은 소멸하며 에너지를 1 얻는다. +9까지 강화할 수 있고 강화마다 에너지 획득량 +1이다. 사용자 확정에 따라 비용 0 스킬이다.

## 대화 선택 규칙

방문 횟수는 해당 캐릭터가 아셀리게를 **이전에 방문한 횟수**를 기준으로 한다. 첫 방문은 0, 두 번째는 1이다.

1. 작성된 캐릭터별 첫 방문·두 번째 방문 대화를 우선한다.
2. 레아르타의 이후 방문에는 현재 1막에 맞는 전용 반복 대화를 사용한다.
3. 다른 모드 캐릭터는 작성된 전용 대사가 없으므로 과성장·선착장 공통 대화로 이어진다.
4. 해당 조건이 없으면 공통 대화 `CommonRest`와 `CommonTower` 중 선택한다. 기본 캐릭터의 두 번째 이후 방문도 여기에 해당한다.

게임 기본 `AncientDialogueSet`은 캐릭터 전용 반복과 공통 반복을 같은 추첨 풀에 넣는다. 아셀리게는 시트의 우선순위를 보존하도록 조우마다 후보를 먼저 골라야 한다. 막별로 필터링한 대화 목록을 공용 canonical 모델에 캐시하면 다음 런에 잘못 적용될 수 있다. 별도의 ‘모든 캐릭터 통틀어 최초 방문’ 대사는 작성되지 않았으므로 새로 만들지 않는다.

## 구현 세부 사항

- 빛나는 피막은 획득 시 덱의 적격 카드 중 무작위로 최대 2장에 원작의 **발아 1**(`Sown`)을 영구 부여해 각 카드를 전투에서 처음 사용할 때 에너지 1을 얻게 한다. 짙푸른 비늘의 **안정**(`Steady`)은 보존을 부여하는 별개의 인챈트다. [효과 재사용 규칙](/docs/adr/0001-reuse-base-game-effects.md)과 [인챈트 슬롯 규칙](/docs/adr/0003-combat-scoped-enchantments-and-legacy.md)을 따른다.
- 휴식은 체력 회복 선택만 센다. 모방된 휴식 회복은 재활성화·잎 강화에 포함하지 않는다. 저주 판정은 알테아 유물로 추가 분류되는 카드도 포함한다.
- 정화의 숨결은 초기 셔플에 발동하지 않는다. 원작의 `CardPile.RandomizeOrderInternal`은 `Hook.ModifyShuffleOrder(..., isInitialShuffle: true)`만 호출하고 `AfterShuffle`은 호출하지 않으며, 실제 재셔플을 마친 `CardPileCmd.Shuffle`만 `Hook.AfterShuffle`을 호출한다. `PlayerCombatState.TurnNumber`는 `1`에서 시작하므로 `> 0` 조건으로는 초기 셔플을 구분할 수 없다.
- 1막 고대 교체는 기본 캐릭터 런으로 누출되지 않는다. `ActModel.DeepCloneFields`가 새 `RoomSet`을 할당하고 `RunState.CreateForNewRun`은 `ToMutable` 복제본을 전달하며, 저장 복원 시 `ActModel.FromSave`도 별도 `RoomSet`을 만든다. 아셀리게 조우 훅은 1막 고대를 교체하기 전에 `run.Acts[0]`에 `AssertMutable`을 호출해 현재 런의 가변 인스턴스만 수정한다.
- 재편 토큰이나 불실 복귀본에 기존 강화 단계를 복원할 때는 `CardModel.UpgradeInternal`과 `FinalizeUpgradeInternal`을 사용해 `DeepBlueScales` 횟수를 소모하지 않는다. 마검의 숙명은 기존 강화 단계와 전투 인챈트를 먼저 복원한 뒤 실제 강화 명령을 한 번 실행한다.
- 생명의 원천은 원래 분기와 보스 연결을 유지하면서 보물방 다음에 휴식 층을 삽입한다. 획득 시 현재 지도를 다시 생성하며, 저장된 지도는 재삽입하지 않는다. 같은 파티에 여러 개 있어도 한 층만 추가한다. 블리츠 모드에서는 허용되지 않으며, 획득 시 지도를 재생성하지 않고 일반 런 생성 지도(`StandardActMap`, `SpoilsActMap`, `GoldenPathActMap`)에만 휴식 층을 삽입해 `BlitzActMap` 등 특수 지도를 보존한다.
- 블리츠 및 모디파이어 선택 경로는 원작 니오우와 동일하게 런 기록의 고대 유물 선택(`AncientChoices`)에 중복 기록하지 않는다.
- 깊은 숨의 소모 여부, 비늘 사용 횟수, 묘목 진행 횟수, 생장하는 축복의 전투 횟수 및 아직 지급하지 않은 보상 여부를 저장한다. 조화로운 축복의 병 속의 요정은 포션 칸이 찬 경우에도 선택할 수 있게 보상 화면으로 지급한다.
- 레아르타의 선착장 대사 숫자는 이전 아셀리게 방문 횟수 +2로 표시한다. 디펙트의 연출 지시 `<알아듣기 힘든 무작위 문장>`은 임시로 `…?`로 표시한다. 새 음성은 없다.
- 2막 이후 랜덤 고대 풀에는 아셀리게를 넣지 않으며, 선택지 유물 14종은 유물 도감에 노출한다.

Orobas 유물 변형과 아키텍트 대사는 별도 작업이다.

## 대화 원문

아래 행 번호는 시트의 위치이며, 코드 식별자는 `AseligeConversation`과 대응한다. 인용문 내부 표현은 원문을 유지한다.

### IroncladFirstVisit (2행)

```text
Ancient: 경멸받을 존재에게 영혼을 팔았구나. 가엾은 것.
Character: ...
Ancient: 여기서 너를 죽여봤자, 결국 꼭두각시 신세를 면할 수는 없겠지. 내가 조금 도와주마.
```

### SilentFirstVisit (3행)

```text
Ancient: 그 끝없는 향상심이 너를 이 곳으로 불렀군. 가장 위대한 사냥을 바라는가?
Character: ...
Ancient: 피가 아니면 찾지 못할 영광이라. 지독하군.
```

Ancient: 도움이 되지 못해 미안하구나.
