# 정록 용, 아셀리게 — 1막 고대의 존재

기준: [카드 기획 시트의 ‘고대’ 탭](https://docs.google.com/spreadsheets/d/1rwlbeGbN32cwy-rOZWJzCIR_Rhyx5rmiezInGhioEq0/edit), 2026-10-23 확인. 아래 내용은 이 날짜의 기획과 사용자가 대화에서 확정한 사항을 함께 정리한 것이다. 시트의 A–E열은 대화, F–I열은 유물 목록이며 같은 행에 있다는 이유로 두 항목을 연결하지 않는다.

## 현재 작업 상태

2026-10-24: 아셀리게의 고대 모델, 14종 유물 효과, 지급 카드 2종, 대화 13종, 1막 교체 및 저장 상태를 구현했다. 승인한 숲 배경 메인 그림과 귀여운 대화 아이콘, 유물 이미지 42개를 연결했다. 이미지 경로는 [에셋 문서](../characters/aselige/aselige-assets.md)에 정리했다.

C# 빌드 오류·경고 0건. 임시 네이티브 헤드리스 관찰 82건에서 카드 지급·강화, 유물 저장 복원, 지도 추가 층과 복원, 실제 방 생성 경로, 대화 및 선택지, 보상 조건을 확인했다. 앞선 규칙 관찰 320건과 별개이다. 정식 테스트나 CI는 추가·변경하지 않았다. 전체 패키지 내보내기 및 기존 리그 검사도 통과했고, 패키지의 이미지·대화와 세 화면 비율을 확인했다. 결과물은 `artifacts/mods/Sts2WD/`에 있다. 2026-10-24 전체 패치와 함께 로컬 설치를 완료했고, 설치 파일 4개의 해시가 일치했다. 설치된 PCK의 리소스 로드도 통과했다. 실제 플레이 화면·멀티플레이 통신 검증은 아직 수행하지 않았다.

## 확정한 조우 규칙

- 고대의 전체 표시 이름은 **정록 용, 아셀리게**이다. 한국어 `STS2WD-ASELIGE.title`에 전체 문자열을 저장해 이름만 읽는 화면에서도 호칭이 빠지지 않도록 한다. `.epithet`은 중복 표시를 피하도록 비워 두며, 영문 표시는 `Verdant Dragon, Aselige`로 둔다. 고대 모델은 이 이름으로 등록되어 있다.

- 파티에 모드 캐릭터가 한 명이라도 있으면 1막 시작 고대의 존재를 아셀리게로 대체한다. 혼합 멀티플레이의 기본 캐릭터도 아셀리게를 만난다.
- 기본 캐릭터만 있는 런에서는 니오우를 유지한다. 2막 이후의 고대의 존재는 이 조건으로 교체하지 않는다.
- 모드 캐릭터 판정은 현재 `Realta`, `Althea`, `CharacterThree`, `CharacterFour`(Erenil) 타입을 사용한다. Althea 명칭은 병합한 최신 main을 따른다. 이 조우 작업에서 추가로 캐릭터 ID를 바꾸지 않는다.
- 각 플레이어는 아래 세 묶음에서 하나씩 선택지를 받는다. 포용의 피리의 자격은 해당 플레이어에게 적용하며, 같은 파티의 다른 캐릭터에게 전파하지 않는다.
- ‘깊은 숨’ 재활성화 및 ‘작은 새싹’ 강화의 **휴식**은 휴식 장소에서 **체력 회복을 선택했을 때**이다. 단순 입장이나 제련은 포함하지 않는다.
- ‘정록 용의 강림’은 연계 캐릭터가 확정될 때까지 효과 없는 더미 카드로 둔다. 비용 0 스킬이며, 효과·강화는 없다.

빛나는 잎은 소멸하며 에너지를 1 얻는다. +9까지 강화할 수 있고 강화마다 에너지 획득량 +1이다. 사용자 확정에 따라 비용 0 스킬이다.

## 대화 선택 규칙

방문 횟수는 해당 캐릭터가 아셀리게를 **이전에 방문한 횟수**를 기준으로 한다. 첫 방문은 0, 두 번째는 1이다.

1. 작성된 캐릭터별 첫 방문·두 번째 방문 대화를 우선한다.
2. 레아르타의 이후 방문에는 현재 1막에 맞는 전용 반복 대화를 사용한다.
3. 다른 모드 캐릭터는 작성된 전용 대사가 없으므로 과성장·선착장 공통 대화로 이어진다.
4. 해당 조건이 없으면 공통 대화 `CommonRest`와 `CommonTower` 중 선택한다. 기본 캐릭터의 두 번째 이후 방문도 여기에 해당한다.

게임 기본 `AncientDialogueSet`은 캐릭터 전용 반복과 공통 반복을 같은 추첨 풀에 넣는다. 아셀리게는 시트의 우선순위를 보존하도록 조우마다 후보를 먼저 골라야 한다. 막별로 필터링한 대화 목록을 공용 canonical 모델에 캐시하면 다음 런에 잘못 적용될 수 있다. 별도의 ‘모든 캐릭터 통틀어 최초 방문’ 대사는 작성되지 않았으므로 새로 만들지 않는다.

## 구현 세부 사항과 확인 범위

- 메르쿠리우스는 세 번째 캐릭터 `CharacterThree`에 연결했다. 두 지급 카드는 비용 0 스킬이다. 정록 용의 강림은 효과 없는 더미이며 강화되지 않는다.
- 빛나는 피막은 획득 시 덱의 적격 카드 중 무작위로 최대 2장에 원작의 **발아 1**을 영구 부여한다. 각 카드를 전투에서 처음 사용할 때 에너지 1을 얻는다. 짙푸른 비늘의 **안정**은 보존을 부여하는 별개의 인챈트다. [효과 재사용 규칙](../adr/0001-reuse-base-game-effects.md)과 [인챈트 슬롯 규칙](../adr/0003-combat-scoped-enchantments-and-legacy.md)을 따른다. 이 교정은 수정 이후의 유물 획득에 적용되며, 기존 저장에 부여된 안정은 그대로 유지된다.
- 휴식은 체력 회복 선택만 센다. 모방된 휴식 회복은 재활성화·잎 강화에 포함하지 않는다. 초기 전투 셔플은 정화의 숨결을 발동시키지 않는다. 저주 판정은 Althea 유물로 추가 분류되는 카드도 포함한다.
- 생명의 원천은 원래 분기와 보스 연결을 유지하면서 보물방 다음에 휴식 층을 삽입한다. 획득 시 현재 지도를 다시 생성하며, 저장된 지도는 재삽입하지 않는다. 같은 파티에 여러 개 있어도 한 층만 추가한다.
- 깊은 숨의 소모 여부, 비늘 사용 횟수, 묘목 진행 횟수, 생장하는 축복의 전투 횟수 및 아직 지급하지 않은 보상 여부를 저장한다. 조화로운 축복의 병 속의 요정은 포션 칸이 찬 경우에도 선택할 수 있게 보상 화면으로 지급한다.
- 레아르타의 선착장 대사 숫자는 이전 아셀리게 방문 횟수 +2로 표시한다. 디펙트의 연출 지시 `<알아듣기 힘든 무작위 문장>`은 임시로 `…?`로 표시한다. 새 음성은 없다.
- 실제 게임의 `RunManager.GenerateRooms`, `AncientDialogueSet`, 카드 강화·유물 획득 명령을 연결했다. 2막 이후 랜덤 고대 풀에는 아셀리게를 넣지 않는다. 등록된 선택지 14종은 유물 도감에도 노출한다.

Orobas 유물 변형과 아키텍트 대사는 별도 작업이다. 현재 확인은 임시 네이티브 관찰과 빌드에 한정되며, 실제 플레이·멀티플레이 동기화 검증은 남아 있다.
## 대화 원문

아래 행 번호는 기준 날짜 시트의 위치이며, 코드 식별자는 `AseligeConversation`과 대응한다. 인용문 내부 표현은 원문을 유지한다.

### IroncladFirstVisit (2행)

```text
Ancient: 경멸받을 존재에게 영혼을 팔았구나. 가엾은 것.
Character: ...
Ancient: 여기서 너를 죽여봤자, 결국 꼭두각시 신세를 면할 수는 없겠지. 내가 조금 도와주마.
```

### SilentFirstVisit (3행)

```text
Ancient: 그 끝없는 향상심이 너를 이 곳으로 불렀군. 가장 위대한 사냥을 바라는가?
Character: ...
Ancient: 피가 아니면 찾지 못할 영광이라. 지독하군.
```

### DefectFirstVisit (4행)


### NecrobinderFirstVisit (6행)

