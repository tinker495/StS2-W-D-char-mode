# 레아르타의 인챈트 부여는 전투 한정이고, 유산만 여러 인챈트를 가진다

기존 게임의 인챈트는 덱 카드에 영구히 붙고 카드당 한 슬롯만 쓴다. 레아르타는 전투 중에 카드를 성장시키는 캐릭터이므로, 개선 같은 부여 효과는 기본적으로 해당 전투에서만 유지되게 하고 영구 부여는 고대 카드(`천재의 영감`)의 예외로만 둔다. 일반 카드는 기존 게임처럼 인챈트 하나만 가지며, 이미 인챈트가 있으면 같은 종류라도 추가 부여나 교체의 대상이 되지 않는다. 유산 키워드가 있는 카드만 이 제한을 벗어나 같은 인챈트를 반복해서 받거나 여러 종류를 함께 가진다.

## Considered Options

- **영구 부여를 기본으로 한다.** 기존 게임과 일관되지만, 매 전투 개선을 쌓는 시작 덱 구조에서 덱이 지나치게 빨리 완성된다. 채택하지 않았다.
- **모든 카드가 여러 인챈트를 가진다.** 유산의 정체성이 사라지고, 기존 카드와 인챈트의 상호작용을 전부 다시 검토해야 한다. 채택하지 않았다.

## Consequences

- 전투 카드는 덱 카드의 복제본(`CardModel.DeckVersion`)이다. 따라서 전투 중 복제본에 부여한 인챈트는 전투가 끝나면 함께 사라지고, 덱 카드의 영구 인챈트는 영향을 받지 않는다.
- 일시적 인챈트는 같은 종류의 영구 인챈트와 수치나 설명 항목을 합치지 않고 다른 색으로 따로 표시한다. 예: 영구 예리 3 + 일시적 예리 2. 같은 유지 범위의 같은 인챈트끼리는 합산해서 표시한다.
- 기존 게임의 카드는 인챈트 슬롯이 하나뿐이고 `Sharp`·`Adroit`는 같은 종류끼리도 겹쳐 받지 못한다(`IsStackable == false`). 그래서 영구 인챈트 하나로 표현할 수 없는 상태, 곧 유산의 복수 인챈트나 일시적 인챈트가 있으면 슬롯에 묶음 인챈트(`RealtaCompositeEnchantment`)를 둔다.
  - 묶음 인챈트는 기존 인챈트 인스턴스를 항목으로 담고, 피해·방어도·재사용 횟수·사용 시 효과·훅을 모두 항목에 위임한다. 기존 게임 코드는 슬롯만 읽으므로 그대로 동작한다.
  - 유산 예외는 카드 단위 규칙(`RealtaEnchantments`)이 소유한다. 개선뿐 아니라 이벤트·유물 같은 기존 게임의 영구 부여도 유산에는 제한 없이 적용된다. 일반 카드는 슬롯이 차 있으면 어떤 경로로도 다시 인챈트할 수 없다.
  - 영구 항목은 저장되고, 일시적 항목은 전투 카드에만 생긴다.
  - 슬롯 인챈트를 통째로 다른 카드에 옮기는 기존 효과(Claws의 Maul 변환 등)는 묶음 인챈트를 옮기지 않는다. 영구 항목을 하나씩 대상 카드의 규칙대로 다시 부여하므로 일반 카드는 그중 하나만 받는다.
  - 덱 인챈트 화면의 미리보기도 같은 규칙으로 계산해, 유산 카드의 기존 인챈트가 미리보기에서 사라지지 않게 한다.
- 영구 항목은 기존 인챈트 문구와 같은 `[purple]`로, 일시적 항목은 다른 색으로 따로 한 줄씩 표시한다. 구체적인 색은 아직 정하지 않았으며, 정할 때까지 임시로 `[aqua]`를 쓴다.
- 표시 분리는 일반 카드의 인챈트 하나 제한을 완화하지 않는다.
- 알려진 한계: 기존 게임에는 슬롯의 인챈트 종류를 직접 확인하는 곳이 있다(휴식처의 `Clone`, Thieving Hopper의 `Imbued`). 이런 곳은 묶음 안에 든 해당 인챈트를 찾지 못한다.
