# 레아르타가 타격·수비의 카드 모델을 소유한다

레아르타의 시작 타격·수비는 `RealtaStrike`·`RealtaDefend`로 정의하여 `RealtaCardPool`에 등록한다. 게임의 기본 변환은 카드 자신의 풀을 사용하므로, Ironclad 모델을 공유하면서 변환 메서드를 패치하면 카드 소속과 변환 후보의 의미가 어긋나고 외부 메서드의 구현에도 의존하게 된다. 사용자는 2026-10-18에 전용 타격·수비로 소속을 바로잡는 방향을 선택했다.

비용·수치·강화 효과와 Strike/Defend 태그는 원본을 따른다. 그림은 기존 임시 리소스를 재사용할 수 있다. 새 모델 ID는 저장 호환의 일부이므로 이후 이름 변경에도 이관을 고려한다.

기존 레아르타 런은 플레이어 복원 시 덱의 `StrikeIronclad`·`DefendIronclad` ID만 새 ID로 이관하고 기존 카드의 저장 속성을 유지한다. 과거 데이터는 해당 모델을 공유하는 카드의 획득 출처를 구별할 수 없으므로 두 ID를 모두 이관한다. 다른 캐릭터의 덱과 과거 런 기록은 이관하지 않는다. 일반 무작위 변환과 명시 결과 변환은 게임의 원래 경로를 사용한다.
