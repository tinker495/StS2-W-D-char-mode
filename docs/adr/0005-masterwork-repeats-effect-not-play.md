# 역작은 카드를 여러 번 사용하지 않고, 한 번의 사용 안에서 효과를 반복한다

역작은 소비한 에너지 X만큼 한 카드의 효과와 그 카드의 인챈트 효과를 총 X회 반복하는 X코스트 테마다. 기존 게임의 재사용(replay)처럼 카드를 여러 번 사용한 것으로 취급하지 않는다. 카드 사용 횟수에 반응하는 효과가 X배로 불어나는 것을 막고, 숙련처럼 사용 시 발동하는 인챈트를 반복마다 다시 실행해 인챈트를 많이 쌓은 카드가 보상을 받게 하려는 결정이다.

## Considered Options

- **기존 재사용(`BaseReplayCount`) 사용.** 구현은 간단하지만 카드 사용 횟수 판정과 사용 시 효과가 모두 X배가 되어 설계 의도와 다르다. 채택하지 않았다.

## Consequences

- 활력은 모든 반복 공격에 적용되고 전체 실행이 끝난 뒤 한 번만 소모된다. 기본 피해 4, X=3, 활력 2라면 피해 6을 3회 준다. `VigorPower`는 `AttackCommand` 하나가 끝날 때 소모되므로, 반복 공격은 활력이 반복 중간에 소모되지 않도록 구성해야 한다. ([ADR-0001](0001-reuse-base-game-effects.md))
- X=0이면 반복은 0회이며 피해와 인챈트 효과를 실행하지 않는다.
- 반복 중 대상이 사망하면 남은 반복은 중단한다.
- 숙련 외 개별 인챈트와의 세부 상호작용은 실제 카드를 추가할 때 확인한다.
