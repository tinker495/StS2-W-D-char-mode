# Reuse Base-Game Powers and Enchantments

Realta's 판금, 활력, 화염, 반사, and retained Block reuse Eternal Armor's `PlatingPower`, Regent Patter's `VigorPower`, Ironclad Flame Barrier's `FlameBarrierPower`, Regent Reflect's `ReflectPower`, and Silent Blur's `BlurPower`, respectively. 예리, 숙련, 기민, 안정, and 발아 reuse `Sharp`, `Adroit`, `Nimble`, `Steady`, and `Sown`. Do not create dedicated powers or enchantments with the same meaning. The existing effects already integrate with other characters, relics, potions, tooltips, and localization; duplicating ownership adds bugs and presentation differences.

## Consequences

- Resolve each named base-game effect against its original type and behavior. When the effect name, a parenthetical explanation, and the described behavior disagree, report the conflicting meanings before selecting an implementation. An explicit user correction settles that choice; retain the request's other constraints. Spec reviews apply the same comparison to the requirements themselves, even when code faithfully implements one interpretation of an inconsistent document.
- Follow the identified effect's behavior. If the intended behavior still differs from the original, report that unresolved difference for a decision rather than substituting another effect or creating a dedicated duplicate. Inspection of game code on 2026-10-16 established:
  - `FlameBarrierPower` retaliates after its owner takes damage from a powered attack and expires at the end of the opposing side's turn. This corresponds to the design's period until the owner's next turn starts.
  - `VigorPower` applies to one `AttackCommand` and is consumed after that command finishes. Masterwork's repeated attacks depend on this. ([ADR-0005](0005-masterwork-repeats-effect-not-play.md))
- Temporary Sharp and Adroit also use the original `Sharp` and `Adroit` instances. When more than one enchantment is needed in the slot, place them inside a composite enchantment. ([ADR-0003](0003-combat-scoped-enchantments-and-legacy.md))
- Card text and the glossary own the mod's localized labels; code uses the original class identifiers. The Korean name for Plating changed from 철갑 to 판금 to match the card table on 2026-10-17.
- Display titles can differ from native model identifiers. `RealtaPowerPresentation` names an applied `BlurPower` on Realta after `RealtaRinnalBodbDearg` and an applied `ReflectPower` after `RealtaSpatialWarp`, using the canonical card title without upgrade suffixes. Other characters retain those powers' native titles. Native instances do not retain the granting card, so this presentation applies to either power on Realta regardless of its source; stacking and behavior remain shared. `FlameBarrierPower` is displayed as 화염 / Flame, including canonical hover tips, while the vanilla Flame Barrier card keeps its card title. Realta's next-turn Vigor timer takes the title of `RealtaWellPrepared`; its separate native next-turn draw power retains its shared functional label. This is presentation only; do not fork powers to rename them.
