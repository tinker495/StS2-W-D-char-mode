# 레아르타 전투·상점 애니메이션은 Godot 씬에서 직접 편집한다

2026-10-22 사용자는 Godot 네이티브 씬·리소스를 유일한 편집 원본으로 삼고, 전투·상점 리그의 기존 동작을 보존하며 다른 편집 방식을 모두 제거하기로 결정했다. 뼈대·메시·가중치·애니메이션을 `.tscn`·`.tres`에서 직접 편집하고 같은 파일을 게임에 패키징한다. 외부 편집 프로젝트와 양방향 변환 도구는 제거해 원본 소유권과 저장 경로를 하나로 모은다.

기존 키를 줄이거나 동작을 재구성하면 보존 요구를 훼손할 수 있으므로 촘촘한 키를 유지한다. 편집 편의보다 현재 동작 보존을 우선하며, 키 단순화는 별도 결정으로 남긴다. 에디터와 실행 중의 표시·겹침 보정은 같은 컨트롤러가 담당하고, 반복 동작의 무작위 진입과 재시작 처리는 실행 중에만 적용한다. 휴식·캐릭터 선택 화면은 이번 범위에서 제외한다.

같은 날 공식 Godot 작업 방식과 비교한 뒤 정적 메시·UV·가중치는 노드에만 저장하고 표시·겹침은 기존 의미 상태 트랙으로 통일했다. 사용자는 저장 기본값 복원을 위한 `RESET` 추가와 해당 이름 검사 수정을 명시적으로 지시했다. 이에 기존 10개 게임 호출 이름에 에디터용 RESET 하나를 허용하며, 정적 메시를 되돌리는 키는 RESET에 넣지 않는다. 나머지 기존 검증 조건은 유지한다.

후속 Standards 리뷰에서 공통 데이터가 전투·상점 두 파일에 복제돼 수동 편집을 반복해야 하는 문제가 확인됐다. 공통 뼈대·메시를 `realta_rig_base.tscn` 하나로 모으고 기존 두 경로는 이를 상속한다. 동일한 여섯 동작은 두 라이브러리가 같은 외부 Animation `.tres`를 참조하며, 변형별 RESET·부활·초기 포즈 차이·호출 연결만 분리한다. 네이티브 리소스를 나누는 것은 다른 저작 방식이나 생성기를 추가하는 것이 아니며, 저장한 씬·리소스를 그대로 패키징하는 원칙은 유지한다.
