# Tiered Texture Compression and Dual PCK Boundary

Use a three-tier `.import` compression policy for `Sts2WD/` textures, paired with a dual non-runtime boundary (`.gdignore` plus hardened `export_presets.cfg` and post-export PCK verification) and `Release`-by-default 3-file installs. Full rules and verification commands live in [Install Package and PCK Minimization](/docs/conventions/packaging/install-package.md).

All 204 initial `.import` files under `Sts2WD/` defaulted to Godot's `compress/mode=0` (Lossless WebP), consuming 19.98 MB of the 21.65 MB PCK (92.3% of file size). While vanilla `SlayTheSpire2.pck` card portraits (`1000x760` flat-shaded lineart) average 204 KB in `VP8L`, this mod's painterly `1000x760` card portraits average ~600 KB (~3x vanilla) and would grow to ~180 MB across 300 cards (four characters). Applying Lossy WebP (`compress/mode=1`, `compress/lossy_quality=0.85`) to large painterly illustrations cuts card portraits to ~51 KB each and selection backgrounds from 5.33 MB to ~0.35 MB while keeping small `<=256px` UI icons, `*_outline.png`, card frames, blink patches, shader materials, and `mod_image.png` lossless to avoid ringing or alpha-fringe artifacts.

Large resident combat atlases (`>=2048px`, such as `Sts2WD/animations/realta/combat/realta_skeleton.png`) use VRAM BPTC/BC7 (`compress/mode=2`, `compress/high_quality=true` with `textures/vram_compression/import_s3tc_bptc=true` in [project.godot](/project.godot) and `texture_format/s3tc_bptc=true`, `texture_format/etc2_astc=false` in [export_presets.cfg](/export_presets.cfg)). Although BC7 stores a fixed 8 bpp across transparent regions (~4.1 MB in PCK vs ~0.56 MB in Lossy WebP), it reduces resident GPU VRAM by 75% (`16.0 MB` RGBA8 to `4.0 MB` BC7) while preserving exact `2048x2048` `Polygon2D.uv` coordinates. `compress/high_quality=true` selects BC7 (`.bptc.ctex`) over BC3 (`.s3tc.ctex`) for crisp linework and smooth alpha gradients; on Compatibility/OpenGL 4.1 hosts lacking `GL_ARB_texture_compression_bptc`, Godot falls back to software decompression, and headless `--import` encodes BC7 via CPU `cvtt` rather than GPU `Betsy`.

Import-time rescaling (`process/size_limit != 0`) is forbidden on all textures because Spine `.spatlas` descriptors ([ADR-0008](/docs/adr/0008-native-spine-rigs-and-artifact-refresh.md)) store region bounds in texel coordinates and `realta_rest.gd` hardcodes blink offsets and lighting masks in source pixel coordinates. Resolution limits are therefore enforced unconditionally on source PNG `IHDR` dimensions, including 4x4 block alignment on Tier 1 atlases.

Rather than switching `export_presets.cfg` to `export_filter="resources"` (which requires regenerating and committing an explicit file list on every new asset), the project retains `export_filter="all_resources"` combined with tracked `.gdignore` markers on non-dot non-runtime directories (excluding `Sts2WDCode/`, whose `.cs`/`.uid` files Godot C# requires), a hardened `exclude_filter`, static `Sts2WD/` PNG reachability checks, and post-export PCK allowlist plus 1:1 `.godot/imported/<file>` provenance verification. `dev.ps1 publish` and `deploy` default to `Release` (omitting debug symbols, cutting the binary payload from 765.3 KB to 354.0 KB), while `CopyToModsFolderOnBuild` is guarded by `IsInnerGodotExport != 'true'` so MegaDot's internal export build cannot overwrite Release outputs or restore debug symbols.
