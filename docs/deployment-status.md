# 공통 배포 상태

여러 캐릭터에 걸친 패키지·설치·검증 기록을 이 문서에서 관리한다. 캐릭터별 에셋 경로와 적용 범위는 각 에셋 가이드가 관리한다. 아래 내용은 원래 배포 환경의 관찰 기록이며, 현재 체크아웃이나 다른 PC의 설치 상태를 뜻하지 않는다.

## 2026-10-25 최신 main 및 유물 정정 배포

`origin/main`의 `13bab91`까지 갱신하고 로컬의 빛나는 피막 발아(`Sown`) 정정 및 재생의 은총 한·영 설명 수정을 함께 설치했다. 이전 설치는 알테아 아트 반영 전의 `06870eb`에 기반했으므로 최신 이미지가 빠져 있었다. 재생의 은총의 한국어 설명은 “? 방에서 휴식 장소를 발견할 수 있습니다. 체력이 낮으면, 더 높은 확률로 발견합니다.”이며 확률 계산은 변경하지 않았다.

`dev.ps1 deploy`는 종료 코드 0, C# 경고·오류 0건으로 완료했고 Steam 게임의 `mods/Sts2WD/`에 설치한 DLL·PCK·manifest·PDB 네 파일의 SHA-256이 패키지와 일치했다. 설치 PCK를 별도 프로세스에서 로드해 알테아의 선택 초상화·잠금 초상화·선택 배경·캐릭터 아이콘·외곽선·지도 마커·전신 그림 7개를 현재 소스와 비교했다. 비교에는 각 `.import`의 알파 경계 보정을 동일하게 적용했다. 전투·휴식·상점·캐릭터 선택 장면 4개를 인스턴스화했고, 두 언어의 수정 유물 설명을 읽어 확인했다. 실제 게임 플레이와 멀티플레이는 검증하지 않았다.

개발용 MCP 플러그인의 이전 패키징 종료 오류를 피하도록 패키징 중에만 해당 플러그인·개발 autoload를 비활성화했고 `project.godot`은 종료 후 바이트 단위로 원상 복원했다. 로컬 설정 및 작업 파일은 보존했다. 백업과 배포 진단은 빌드·설치 절차가 생성한 로컬 기록으로 보관했다. 공유 문서의 재현 절차는 해당 개인 기록을 요구하지 않는다. 정식 테스트나 검증 기준을 변경하지 않았다.

| 빌드 결과 | C# 경고 0개, 오류 0개 |

임시 네이티브 관찰에서는 최신 카드 51건, 아셀리게 동작 82건, 현지화·소스 확인 25건을 통과했다. 설치된 PCK에서 유물 텍스처 72개, 대화 아이콘 2개, 언어별 대사 34줄과 고대의 존재 전체 그림을 로드했고, 세 가지 뷰포트 크기에서 표시를 확인했다.

이 관찰은 정식 인수 테스트가 아니다. 당시 작업은 정식 테스트와 검증 설정을 변경하지 않았고, 기준 브랜치에서 가져온 변경도 유지했다. 게임 실행과 대화형 멀티플레이는 확인하지 않았다. 애니메이션을 변경하지 않아 `dev.ps1 anim`에서 실행하는 애니메이션 검사는 이 배포에서 재실행하지 않았다.

배포 재현은 [빌드·설치 절차](../.agents/skills/build-install/SKILL.md)를 따른다. 원래 실행의 개인 경로나 임시 로그 없이도 위 기록으로 범위와 검증 한계를 확인할 수 있다.
