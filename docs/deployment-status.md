# 공통 배포 상태

여러 캐릭터에 걸친 패키지·설치·검증 기록을 이 문서에서 관리한다. 캐릭터별 에셋 경로와 적용 범위는 각 에셋 가이드가 관리한다. 아래 내용은 원래 배포 환경의 관찰 기록이며, 현재 체크아웃이나 다른 PC의 설치 상태를 뜻하지 않는다.

## 2026-10-24 카드·유물·아셀리게 배포

| 항목 | 기록 |
|---|---|
| 소스 | `feat/aselige-relics-althea-update`, 기준 `origin/main` 커밋 `f48f6da` |
| 적용 범위 | 당시 카드 밸런스, 알테아 신규 카드 3종, 레아르타·알테아 각각 유물 일러스트 5종, Retain 강조 표시, 아셀리게 조우 |
| 패키지 | `artifacts/mods/Sts2WD/`의 DLL, PCK, JSON manifest, PDB |

| 배포 결과 | 종료 코드 0, 패키지 파일 4개와 설치본의 SHA-256 일치, 로컬 백업·진단 로그 보관 |
| 빌드 결과 | C# 경고 0개, 오류 0개 |

임시 네이티브 관찰에서는 최신 카드 51건, 아셀리게 동작 82건, 현지화·소스 확인 25건을 통과했다. 설치된 PCK에서 유물 텍스처 72개, 대화 아이콘 2개, 언어별 대사 34줄과 고대의 존재 전체 그림을 로드했고, 세 가지 뷰포트 크기에서 표시를 확인했다.

이 관찰은 정식 인수 테스트가 아니다. 당시 작업은 정식 테스트와 검증 설정을 변경하지 않았고, 기준 브랜치에서 가져온 변경도 유지했다. 게임 실행과 대화형 멀티플레이는 확인하지 않았다. 애니메이션을 변경하지 않아 `dev.ps1 anim`에서 실행하는 애니메이션 검사는 이 배포에서 재실행하지 않았다.

배포 재현은 [빌드·설치 절차](../.agents/skills/build-install/SKILL.md)를 따른다. 원래 실행의 개인 경로나 임시 로그 없이도 위 기록으로 범위와 검증 한계를 확인할 수 있다.

캐릭터별 적용 상태: [레아르타](characters/realta/realta-assets.md), [알테아](characters/althea/althea-assets.md), [아셀리게](characters/aselige/aselige-assets.md). 알테아의 이후 standing/UI/selection 아트 적용 여부는 해당 가이드의 Branch B Delivery 기록에서 별도로 확인한다.
