# Triage labels

스킬에서 언급하는 역할을 아래 GitHub 라벨에 대응시킨다.

| 스킬의 역할 | GitHub 라벨 | 의미 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 관리자의 검토와 분류가 필요함 |
| `needs-info` | `needs-info` | 보고자의 추가 정보를 기다림 |
| `ready-for-agent` | `ready-for-agent` | 명세가 정리되어 에이전트가 구현할 수 있음 |
| `ready-for-human` | `ready-for-human` | 사람이 구현해야 함 |
| `wontfix` | `wontfix` | 작업하지 않기로 결정함 |

스킬이 특정 역할의 라벨을 요청하면 이 표의 GitHub 라벨을 사용한다. 이름을 바꾸려면 GitHub 라벨 열을 수정한다.
