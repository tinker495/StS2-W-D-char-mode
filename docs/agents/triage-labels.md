# Triage Labels

Map the roles used by skills to these GitHub labels.

| Skill role | GitHub label | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer review and classification required |
| `needs-info` | `needs-info` | Awaiting more information from the reporter |
| `ready-for-agent` | `ready-for-agent` | Specification is ready for agent implementation |
| `ready-for-human` | `ready-for-human` | A person must implement the work |
| `wontfix` | `wontfix` | Decision not to do the work |

Use the GitHub label in this table when a skill requests a role. To rename a label, update the GitHub label column.
