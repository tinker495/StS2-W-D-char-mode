## 조율

사용자는 시트의 짧은 설명보다 앞서 정한 세 선택지 방식을 우선하도록 확인했다. 지식의 악마처럼 선택지 카드 세 장을 표시한다.

1. 손의 카드 1장을 뽑을 더미 맨 위에 놓는다.
2. 버린 더미의 카드 1장을 뽑을 더미 맨 위에 놓는다.
3. 버린 더미의 모든 카드를 뽑을 더미에 넣고 함께 섞는다.

앞의 두 선택지는 선택한 카드만 이동시키며 셔플을 발동시키지 않는다. 세 번째는 실제 재셔플이므로 방호의 결속 등 셔플 효과와 연계된다. 세 선택지는 항상 표시하며, 선택한 대상 더미가 비었다면 카드 이동은 일어나지 않는다. 손·버린 더미에서 원하는 장수 전체를 고르는 방식은 사용하지 않는다. 선택지 카드는 전투 중 조율 UI용이며 시작 덱·일반 보상으로 지급하지 않는다.

## 재연 — 확정 설계

재연은 이야기 테마의 방향을 카드 생성으로 표현하는 키워드다. 기본적으로 다른 캐릭터 또는 무색의 조건에 맞는 서로 다른 카드 3장을 무작위로 제시하고, 그중 하나를 선택해 휘발성을 부여한 전투용 생성본으로 손에 추가한다. 영구 덱 추가나 다른 후보 출처는 개별 카드에 명시한다.

| 항목 | 확정 규칙 |
|---|---|
| 후보 출처 | 자신이 아닌 다른 캐릭터의 일반 카드 풀 및 무색 카드 풀. 레아르타·알테아 등 모드 캐릭터도 포함한다. |
| 타입·희귀도 | 일반·고급·희귀의 공격 또는 스킬만 허용한다. 기본 타격·수비, 파워, 토큰, 저주, 상태이상, 퀘스트 및 특별 카드는 제시하지 않는다. |
| 획득 경로 | 일반 카드 풀을 기준으로 한다. 고대의 존재·이벤트 전용 카드는 제외한다. |
| 생성 상태 | 미강화·원래 비용이 기본이다. 비용을 무료로 바꾸거나 강화하는 효과는 재연을 사용하는 개별 카드에 명시한다. |
| 추가 특성 | 선택해 얻은 카드에 휘발성을 부여한다. 이미 휘발성이 있다면 중복 부여하지 않는다. 소멸은 별도로 추가하지 않는다. 원래 카드가 가진 다른 특성은 유지한다. |
| 영구 이득 제외 | 최대 체력·골드 획득, 영구 덱의 유리한 변경, 영구 카드 강화·성장·인챈트 등 전투를 지연해 누적할 수 있는 이득을 주는 카드는 제외한다. |
| 회복·포션 제외 | 체력 회복이나 포션 획득 효과를 가진 카드도 후보에서 제외한다. |

휘발성은 손에 남겼을 때의 소멸이며, 사용 직후 반드시 소멸한다는 뜻이 아니다. 따라서 사용 후 버린 더미로 간 카드가 같은 전투에서 다시 돌아와도 영구 이득을 반복 획득하지 못해야 한다. 단순히 휘발성만 붙였다는 이유로 포식 등의 영구 이득 카드를 허용하지 않는다.

반대로 전투 안에서만 성장하거나 이득을 얻고 전투 종료 시 사라지는 효과는 영구 이득이라는 이유만으로 배제하지 않는다. 생성본을 영구 덱 원본과 연결하지 않는 것이 전제다. 원작 생성 금지 설정, 해금 상태 및 싱글/멀티 전용 제한은 재연에서도 존중한다. 후보의 실제 동작을 검토하지 않은 모드 카드는 안전하다고 가정해 자동 편입하지 않는다.

환상은 ‘받거나 주는 피해가 1로 바뀝니다’라는 테마 DB 38행의 독립 효과다. 사용자는 턴 종료 자동 감소를 제외하고, 주거나 받는 양수 공격마다 1 소비하며 0 이하 피해는 무시하도록 확정했다. 구현은 게임의 공격 처리 단위로 세므로 다단·광역도 한 공격당 1회분을 소비하고, 그 공격의 각 타격 피해를 1로 제한한다. 방어도로 막은 양수 공격도 포함한다. 비공격 체력 손실·독·반격 피해 등은 환상으로 제한하거나 소비하지 않는다.

## 추가 카드의 확정 규칙

- 노래는 실제 드로우만 발동한다. 생성·회수로 손에 들어올 때와 손에서 사용할 때는 효과가 없다. 사용 비용은 1이며 사용 후 보통 버려진다. 손에 남으면 휘발성으로 소멸한다.
- 결말은 방식에 관계없이 실제 드로우될 때마다 강화한다. 턴 시작·카드 효과·밑장 드로우를 포함한다. 셔플·생성·회수·손으로 옮기기 자체는 강화 조건이 아니다. 영구 덱 원본의 강화는 유지하되 전투 중 추가 강화는 영구 덱을 변경하지 않는다.
- 권능은 손에 해당 카드만 있을 때 적용한다. 관통하는 빛은 현재 조건에 따라 비용을 0으로 표시한다. 빛나는 혼은 방어도 획득을 총 2(3)회 수행한다. 에스트리드의 천둥은 피해만 두 번 주고 취약은 한 번 부여한다.
- 지도는 그 턴의 일반 버림 결과만 뽑을 더미 맨 위로 바꾼다. 소멸·파워·복제본의 원래 처리 우선순위를 유지한다. 새 효과는 지도 자신에게 적용하지 않으므로 일반적인 첫 사용의 지도는 버려지고, 다음 카드부터 적용한다. 분위기 조절은 휘발성 소멸과 턴 종료 손패 버리기 전에 장당 선택을 수행하며, 중첩마다 한 장씩 옮긴다.
- 조율 완료는 그 턴에 선택지의 처리를 마쳤다는 뜻이다. 빈 더미를 선택해 카드가 이동하지 않아도 조율은 수행한 것으로 센다. 공격적 조롱은 그 턴 동안 비용이 0이 되며 다음 턴에는 조건을 다시 판단한다.
- 화염 채찍은 각 사용마다 이번 턴의 다음 다른 색 카드 사용을 기다린다. 해당 카드 사용 후 피해 효과만 한 번 반복하고, 카드 사용·인챈트 효과를 다시 실행하지 않는다. 무작위 적은 반복 시점에 다시 뽑는다. 여러 대기 효과는 같은 다음 카드 사용으로 각각 발동한다.
- 전설의 일격은 손에 다른 색 카드가 N장이면 모두 버리고 기본 1회+N회 공격한다. 다른 색은 소유 캐릭터의 카드 풀과 다른 풀에 속하는 카드로, 무색·저주·상태이상도 포함한다. 일반 재연의 안전 제한과는 별개다.
- 유아독존은 멀티 전용이며 다른 플레이어가 생성한 카드만 복사한다. 생성된 카드의 강화·비용 변경·인챈트를 계승하고 휘발성을 추가하며 영구 덱 원본과 연결하지 않는다. 유아독존이 만든 복사본은 다른 유아독존을 발동시키지 않는다. 중첩 수만큼 복사한다.
- 광란의 노래는 모든 적의 현재 공격 의도 피해를 다단 합산한다. 공격하지 않는 적은 0이다. 노래 소유자를 대상으로 한 피해 수정 기준으로 계산하며 멀티의 플레이어 수로 다시 곱하지 않는다. 기본은 무작위 적 하나, 강화는 모든 적이 같은 합계만큼 체력을 잃는다. 이 체력 손실은 방어도·힘·약화 등 일반 공격 피해 수정의 영향을 다시 받지 않는다.
- 치유의 손은 이름과 달리 체력을 회복하는 카드가 아니다. 휘발성 부여만 수행한다. 기본 한 장, 강화 시 0장 이상 원하는 장수를 고를 수 있다.
- 선택하는 운명은 다른 타입을 처음 뽑은 시점에 끝난다. 그 카드도 손에 남는다. 실제로 더 뽑을 수 없으면 종료한다. 강화는 비용 감소가 아닌 소멸 제거다.
- 사자와의 대화는 기본 X장·강화 X+1장을 소멸 더미에서 선택해 뽑을 더미 맨 위로 옮긴다. X에는 원작 Chemical X 등의 수정을 적용한다. 대상이 적으면 있는 만큼만 고르고 0장이면 선택창을 열지 않는다. 카드 속의 운명은 뽑은 카드의 현재 표시 비용을 에너지로 얻고, X 비용과 음수 비용은 0으로 센다.

## 10월 28일 추가·수정 규칙

- 극적인 결말의 기본 피해는 10, 신비한 결말의 기본 드로우는 0, 행복한 결말의 기본 방어도는 9로 조정한다. 무제한 강화 규칙은 유지한다. 치유의 손의 기본 비용은 0이다.
- 손기술은 손의 카드 1(2)장을 뽑을 더미 맨 아래에 놓고 1(2)장을 뽑는다. 버리기 효과가 아니며 셔플도 아니다.
- 영감의 노래는 이전 고양의 노래, 손 안의 운명은 이전 카드 속의 운명의 표시명 변경이다. 기존 모델 ID는 유지한다.
- 정신의 창은 원작 공격을 먼저 실행한 후 방어도를 뚫고 실제 체력에 준 피해(`UnblockedDamage`)만큼 추가 비공격 체력 손실을 준다. 환상의 살해자는 자신의 체력이 아니라 대상 적의 체력을 11(15) 감소시킨다.
- 환상 감소 효과는 감소 사건 횟수가 아닌 실제 잃은 수치만큼 발동한다. 수치보다 큰 음수 변경은 남아 있던 수치로 제한한다. 직접 제거하면 남은 수치만큼 발동하며, 마지막 중첩이 0이 되어 제거될 때 다시 발동하지 않는다. 섞여들기는 잃은 환상 1당 중첩 수만큼 뽑는다. 환상의 살해자는 버린 더미에 있을 때만 손으로 이동하므로 이미 손에 있다면 추가 이동하지 않는다.
- 메아리치는 노래는 소유자·턴 단위 배율을 모든 같은 이름의 카드가 공유한다. 첫 사용은 기본, 다음은 2배·4배·8배로 증가하며 턴 종료 시 초기화한다. 피해 표시·계산은 게임이 표현 가능한 정수 피해 범위까지다.
- 옛날 옛적에는 다음 다른 색 카드에 중첩당 추가 사용 1회를 부여한다. 여러 중첩이면 총 사용 횟수를 더하며 해당 다음 카드에 모두 소비한다. 비용은 한 번만 지불하고, 원작의 카드 반복 경로로 각 사용의 효과·인챈트·사용 훅을 처리한다. 턴 종료 시 남은 효과는 사라진다.
- 밑장빼기는 실제 드로우를 수행하므로 노래·드로우 기록·드로우 금지가 적용된다. 카운팅은 손 전체를 아래에 놓고 놓은 장수만큼 뽑는다. 두 카드 모두 기본 소멸·강화 시 소멸 제거다.
- 신비의 비밀은 드로우한 카드가 휘발성이면 원작 자동 사용 경로를 호출한다. 사용할 수 없는 카드를 강제로 사용 가능하게 만들지 않는다. 운명의 종점은 매 반복마다 무작위 적을 다시 고르고, 실제 뽑은 카드가 휘발성일 때만 다음 반복을 수행한다. 뽑을 수 없으면 끝난다. 점복은 뽑은 시점의 휘발성 여부를 보관해 소멸 후 에너지를 지급한다.
- 으뜸패는 손의 한 장을 남기고 다른 손의 카드를 뽑을 더미에 섞는다. 버린 더미는 합치지 않으며 실제 셔플 효과·새김은 발동한다. 결말은 이후 실제로 뽑았을 때 강화된다.
- 무형의 날개는 마지막 손패 사용 여부를 사용 시작 시 보관해, 다른 사용 후 드로우 효과와의 훅 순서에 영향을 받지 않는다. 오리무중은 휘발성 소멸 처리 전에 손을 확인한다. 무한의 음색은 기본 선천성이 없고 강화하면 선천성을 얻는다.
- 안식의 노래·함께 걸어나갈 때는 멀티 전용이다. 안식의 노래는 원작 재생을 모든 살아 있는 플레이어에게 부여한다. 함께 걸어나갈 때는 빈 더미 선택을 포함한 조율 완료마다 소유자 외 플레이어에게 중첩 수만큼 실제 드로우를 적용한다.
- 권능의 말은 공격 후 살아 있는 대상의 현재 HP가 100 이하일 때 원작 기절을 적용한다. 방어도로 막혀 HP가 100보다 높다면 발동하지 않는다.
- 새겨진 기억은 비용 1(0)의 고급 파워이며 영구 이득 카드이므로 일반 전투 생성 후보에서 제외한다. 중첩마다 해당 전투의 카드 보상 중 아직 인챈트되지 않고 네 인챈트를 모두 받을 수 있는 무작위 카드 한 장을 고른다. 새김·안성맞춤·신속 1·안정은 각각 같은 확률이다. 유효한 카드가 없으면 해당 부여는 불발한다. 고른 보상 카드의 인챈트는 영구 덱에 유지된다. 안식의 노래도 반복 회복을 주므로 일반 전투 생성 후보에서 제외한다.
- 새김은 초기 셔플과 전투 중 셔플 모두 맨 아래 배치다. 안성맞춤은 원작대로 전투 중 셔플만 맨 위 배치, 신속은 원작대로 전투당 최초 사용에 드로우, 안정은 원작 보존 인챈트다.

## 완성 목록의 추가 확정 사항

- 결말 5종은 턴 시작·카드 효과·밑장 등 **실제 드로우마다** 제한 없이 강화한다. 초기 셔플·실제 재셔플·맨 위 배치·회수·생성으로 손에 들어오는 것 자체는 강화하지 않는다. 카드의 기본 수치와 강화 증가량은 유지한다. 완벽한 결말도 동일한 드로우 조건을 따른다.
- 전사·영웅·야성·짐승·우정·복수·어둠 이야기 7종은 기본·강화 모두 소멸한다. 탈출·요정·미지 이야기는 이번 소멸 추가 대상이 아니다. 천사 이야기는 기존대로 기본 소멸·강화 시 제거다.
- 오롯한 존재는 조율과 실제 셔플마다 방어도 3(4)를 얻으며 중첩은 합산한다. 조율의 세 번째 선택지로 셔플하면 두 사건이므로 두 번 얻는다. 전투 준비의 초기 무작위화는 실제 셔플 사건이 아니다. 원작 파워의 방어도처럼 민첩으로 늘리지 않는다.
- 여행의 추억은 고급 파워 비용 1(0)이다. 승리 후 중첩마다 카드 보상 하나를 추가하며 다른 캐릭터와 정확한 무색 풀의 일반·고급·희귀 공격/스킬/파워 3종을 제시한다. 재연과 달리 파워·회복·영구 이득 카드도 보통 카드 보상처럼 허용하며, 휘발성을 추가하지 않는다. 원래 카드가 가진 특성은 유지한다. 보통 카드 보상처럼 선택한 카드가 영구 덱에 들어가고 원작의 보상 수정·강화 확률·저장·재굴림 경로를 따른다. 영구 이득 카드인 여행의 추억 자체는 일반 전투 생성 후보에서 제외한다.
- 이야기에 관한 공격 카드의 이전 이름 ‘이야기의 화신’은 ‘옛날 옛적에’로 표시명을 바꾼다. 기존 `MercuriusAvatarOfStories` 모델 ID는 유지한다. 새 희귀 파워 ‘이야기의 현신’은 별도 `MercuriusIncarnationOfStories`이며 비용 3, 기본 휘발성·강화 시 휘발성을 제거하고 보존을 얻는다. 다른 색 카드 사용마다 힘·민첩을 중첩당 1씩 얻는다.
- 완벽한 결말은 비용 0의 희귀 파워다. 기본 에너지 0이며 강화마다 +1이다. 사용할 때 한 번만 현재 수치의 에너지를 얻고 일반 파워 카드처럼 전투 카드에서 제거된다. 매 턴 에너지를 주는 지속 파워는 부여하지 않는다. 미강화 상태에서도 설명에 에너지 0을 명시한다.
- 환영 복제는 비용 1(0)의 희귀 파워다. 플레이어 턴·적 턴 각각 소유자가 실제로 처음 사용하는 카드의 휘발성 복사본을 중첩 수만큼 손에 넣는다. 자동 사용도 포함하고 강화·비용 변경·인챈트를 계승하며 영구 덱 원본과 연결하지 않는다. 같은 카드의 반복 사용은 첫 사용만 대상으로 센다. 파워가 그 턴 두 번째 이후에 부여되었다고 첫 사용 조건을 새로 시작하지 않는다.

## 기존 게임 동작과의 대응

### 이미 구현한 유물·조율

확인한 원작 DLL은 `sts2.dll` 제품 버전 `0.1.0+59260271157f76a2896f0eab5bc6ea1245d8b314`다.

- `GamblingChip.AfterPlayerTurnStart`와 `CardCmd.DiscardAndDraw`: 기본 손패를 뽑은 뒤 버리기·동일 장수 드로우를 처리하는 경로를 사용한다. 교체 대상은 명령 실행 전에 한 번만 확정한다.
- `KnowledgeDemon.ChooseCurse`와 `CardSelectCmd.FromChooseACardScreen`: 원작의 세 카드 선택 UI와 동기화 경로를 재사용한다. 조율의 실제 효과는 세 전용 선택지 모델이 각각 소유한다.
- `TheAbacus.AfterShuffle` 및 `CardPileCmd.Shuffle`: 실제 재셔플 뒤에 발동한다. 초기 `CardPile.RandomizeOrderInternal`은 이 훅을 호출하지 않는다. 방어도는 유물의 비공격 수치로 처리해 민첩으로 늘리지 않는다.
- `ForgottenSoul.AfterCardExhausted`, `PoisonPower`의 체력 감소 경로: 소멸 원인과 별개로 현재 휘발성 키워드를 확인하고, 전투 대상 전용 RNG로 적을 고른다. 체력 감소는 원작의 방어도 무시·비공격 피해 경로를 사용한다. 원작의 모든 체력 감소 반응까지 우회하는 직접 수치 대입은 하지 않는다.

### 이야기 카드

- `CardFactory.GetDistinctForCombat`는 플레이어 수·전투 생성 금지 필터, 중복 없는 표본 추출과 전투용 카드 생성을 맡는다. 타입·희귀도 허용 목록은 재연이 추가한다. `Discovery.OnPlay`의 선택 UI를 사용하지만 무료 비용 효과는 가져오지 않는다.
- `ColorlessCardPool`을 직접 참조한다. `EventCardPool.IsColorless`도 참이므로 그 플래그 전체를 무색 후보로 사용하지 않는다.
- `Feed`, `HandOfGreed`, `NotYet`, `Alchemize`, `HiddenGem`, `TheHunt`의 원작 생성 금지를 유지하고 회복하는 `Spur`를 추가로 제외한다. Realta·Althea 풀도 조사했으며, 외부 모드의 미검토 풀은 자동 허용하지 않는다.
- `GeneticAlgorithm.OnPlay`·`TheScythe.OnPlay`의 영구 성장은 `DeckVersion`이 있을 때만 발생한다. 재연은 원본의 `CanonicalInstance`에서 새 전투본을 만들고 영구 덱 원본과 연결하지 않으므로 전투 중 성장만 남는다.
- 강화된 선택지 미리보기는 `UpgradeInternal`·`FinalizeUpgradeInternal`을 사용한다. 선택한 카드 한 장만 실제 `CardCmd.Upgrade`를 호출해 비늘 등 강화 유물의 횟수를 미리보기 3장에 낭비하지 않는다.
- `Armaments.OnPlay`처럼 손 선택 후 `CardCmd.Upgrade`로 전투 카드만 강화한다. 약화·취약·별·소환도 원작 효과를 재사용한다.
- `CombatManager.WinCombat`는 `AfterCombatEnd` → 파워 제거 → `AfterCombatVictory` 순서다. 이야기 수집은 파워가 남아 있는 `AfterCombatEnd`에서 전체 `History.CardPlaysStarted`를 읽고 선택을 기다린다. 선택한 런 소유 카드를 `CardPileCmd.Add(..., Deck)`로 추가한다. 일반 카드 보상 재굴림이 후보 조건을 바꾸지 않도록 직접 선택 UI를 사용한다.
- 원작 `IllusionPower`는 몬스터 부활용이며 플레이어에게 적용할 수 없다. `IntangiblePower`는 받는 피해만 제한하므로 환상의 양방향 효과를 그대로 대신하지 않는다.
- 환상은 `ModifyDamageCap`에서 양방향 공격 피해 상한을 1로 적용하고, `AfterAttack`에서 해당 공격의 `DamageResult.TotalDamage`가 양수인 경우 한 번 감소한다. `TotalDamage`는 방어도로 막힌 피해도 포함한다. 미리보기는 소비하지 않으며, 이미 피해 1인 공격도 소비한다. `AfterSideTurnEnd`는 구현하지 않아 턴 종료로 감소하지 않는다.

### 10월 28일 원작 연결점

- 확인한 DLL 제품 버전은 앞선 조사와 동일하다. `Swift`, `PerfectFit`, `Steady`, `RegenPower`, `CreatureCmd.Stun`을 원작 타입 그대로 사용한다. `Imbued`는 초기 맨 아래 배치 외에 자동 사용 동작도 있어 새김으로 재사용하지 않는다.
- `ModifyCardPlayCount`·`AfterModifyingCardPlayCount`는 원작 Burst/Duplication 파워와 같은 반복 경로다. 새로 부여한 재사용 효과가 그 부여 카드 자체에 즉시 소비되지 않는다.
- 환상은 `BeforePowerAmountChanged`에서 기존 수치를 보관하고 `AfterPowerAmountChanged`에서 실제 감소량을 계산한다. 직접 제거는 자기 `AfterRemoved`에서 처리한다. `MercuriusIllusionLossListener`는 버린 더미 회수와 드로우 두 구현이 공유하는 감소 통보다. 별도 전역 파워 제거 패치는 추가하지 않는다.
- `CardPileCmd.Draw`를 사용해야 드로우 기록·노래·금지가 함께 작동한다. 밑장 드로우는 유효한 경우 맨 아래 카드를 맨 위로 옮긴 뒤 원작 드로우 명령을 사용한다. 드로우가 금지되거나 손이 가득 찼다면 순서를 바꾸지 않는다.
- 원작 셔플 명령은 버린 더미 전체를 합치므로 으뜸패에 그대로 쓰지 않는다. 뽑을 더미만 원작 셔플 RNG·순서 변경 훅으로 섞고 실제 `AfterShuffle`을 발행한다.
- `AfterCombatEnd` 이후 파워가 제거되고 나서 `RewardsSet.GenerateWithoutOffering`가 옵션을 만든다. 새겨진 기억은 전투 방·플레이어별 중첩을 약한 참조에 보관하고 그 보상 세트의 생성 완료 후 한 번만 소비한다. 다른 방·플레이어에게 넘어가지 않는다. 무작위 선택은 각 플레이어의 원작 보상 RNG(`PlayerRng.Rewards`)를 사용한다.
- 보상 재굴림은 보상 세트를 거치지 않고 `CardReward.Populate`로 옵션을 바꾼다. 처음 부여된 각 카드 보상의 부여 횟수를 `AfterGenerated`에 연결해 재생성 옵션에도 적용한다. 생성된 인챈트는 원작 `CardCmd.Enchant`와 저장 경로를 사용한다.

### 완성 목록의 연결점

- 결말은 카드 자신의 `AfterCardDrawn`에서 `card == this`일 때 `CardCmd.Upgrade`를 실행한다. 이전 `AfterShuffle` 강화는 제거했다. 밑장 드로우도 원작 드로우 명령을 사용하므로 같은 조건을 만족한다.
- 조율 완료는 공통 명령에서 오롯한 존재에 알리고, 셔플은 원작 `AfterShuffle`에서 따로 받는다. 두 사건을 임의로 합치지 않는다.
- 여행의 추억은 파워가 남아 있는 `AfterCombatEnd`에서 `CombatRoom.AddExtraReward`를 사용한다. 보상은 실제 다른 캐릭터·무색의 풀 ID를 담은 `CardCreationOptions`와 일반 전투 희귀도 확률로 구성한다. 직렬화할 수 없는 임의 카드 목록·필터 델리게이트를 사용하지 않는다.
- 환영 복제는 원작 Echo Form처럼 `History.CardPlaysStarted`의 소유자·현재 턴·`IsFirstInSeries`를 기준으로 판단한다. 사용 중 신비의 비밀 등이 다른 카드를 자동 사용해도 첫 원본 카드를 놓치지 않도록 `BeforeCardPlayed`에서 첫 사용을 보관하고 `AfterCardPlayed`에서 복사한다. 원작은 `BeforeCardPlayed` 다음에 시작 기록을 추가한다.

## 명칭과 저장 호환성

이름이 결정된 캐릭터는 이름 기반 경로를 사용하는 저장소 규칙에 따라 기존 `CharacterThree` 코드·풀·기반 타입을 `Mercurius`로 정리했다. UI 이미지 경로는 `Sts2WD/images/charui/mercurius/`, 문장 프리셋은 `Sts2WD/character_text/mercurius.json`이다. 아셀리게의 메르쿠리우스 전용 선물 대상도 새 타입에 연결한다.

캐릭터 모델 ID는 `STS2WD-CHARACTER_THREE`에서 `STS2WD-MERCURIUS`로 바뀐다. 기존 자리표시 캐릭터로 진행하던 저장의 자동 이전은 구현하지 않는다. 새 런에서 확인해야 한다. 이번 기본 덱 교체도 새 런부터 적용한다. 기존 저장에 이미 들어 있는 원작 타격·수비를 자동 변환하지는 않으므로, 이전 임시 메르쿠리우스 런에서는 해당 카드가 다른 색으로 남을 수 있다. 이미지 경로 이동은 소스 파일과 import 경로·해시를 함께 갱신하며 기존 스크립트 UID는 유지한다.

유물 그림은 [아트 명세](mercurius-art.md)와 [에셋 상태](mercurius-assets.md)를 따른다. 용의 이정표는 사용자가 선택한 네 번째 반지 시안이다. 이 문서와 구현의 작성은 게임 설치·실제 플레이 확인을 뜻하지 않는다.

완성 시트 79종과 기본 타격·수비 2종, 총 81종을 반영했다. 결말의 드로우 강화·7종 이야기의 소멸·새 파워 5종·표시명 변경·한영 설명을 포함한다. C# 빌드는 경고·오류 0건이다. 임시 네이티브 관찰 330건(효과·경계 168건, 81종 한영 기본·강화 포맷 162건)이 성공했으며 엔진 종료 코드도 0이다. 결말의 일반·턴 시작·밑장 드로우 강화와 셔플·회수·생성·금지된 드로우 제외, 영구 덱 미반영을 확인했다. 이야기 카드 7종의 기본·강화 소멸, 오롯한 존재의 두 사건 발동, 이야기의 현신의 특성 교체·힘·민첩, 완벽한 결말의 에너지 0 표시·일회 지급·파워 카드 제거, 환영 복제의 턴·자동 사용·중첩 자동 사용의 첫 원본 보존을 확인했다. 여행의 추억은 원작 추가 보상·3종 옵션·영구 보상·직렬화 경로를 확인했다. 임시 환경의 보상 UI 동기화 객체만 대체했으며 실제 UI·멀티 네트워크·게임 설치·Git 업로드는 수행하지 않았다. 정식 테스트·CI는 추가하거나 변경하지 않았다. 기존 미추적 파일 참조 문제도 Git 등록 상태를 바꾸지 않아 남아 있다.

### 이전 전체 카드 추가 작업

최신 시트 50종을 모두 구현했고, 기본 타격·수비도 메르쿠리우스 소속 별도 모델로 추가했다. 총 52종이며 조율 선택지 3종은 별도다. 기본 타격·수비가 아이언클래드 소속으로 남아 잘못 다른 색으로 세어지는 문제를 방지한다. 기본 덱과 기존 이야기 카드의 새 수치·효과·표시명도 반영했다. 원작 임시 그림을 사용하고, 이번 작업에서 전용 이미지 생성·게임 설치·Git 업로드는 하지 않았다. 최종 C# 빌드는 경고·오류 0건이다. 임시 네이티브 환경에서 효과·경계 관찰 100건과 52종의 한영 기본·강화 설명 포맷 104건, 총 204건이 성공했으며 엔진 종료 코드도 0이다. 노래의 실제 드로우와 손 생성 구분, 반복 결말 강화·영구 덱 미반영, 조율 비용 감소·만료, 권능의 손 조건, 지도의 자기 버림·후속 카드 맨 위 이동·소멸 우선순위, 턴 종료 선택, 상태 계승 복사·두 플레이어의 재귀 방지, 화염 채찍과 다른 색 연계, 의도 합산을 확인했다. 지도와 사자와의 대화는 원작 OnPlayWrapper로 실행했고, 사자와의 대화의 X=0·2·부족한 더미·빈 더미·소멸, 카드 속의 운명의 변경된 표시 비용·X·음수 비용도 확인했다. 정식 인수 테스트가 아닌 임시 관찰이며 실제 UI 조작·멀티 네트워크 전체 플레이는 검증하지 않았다. 정식 테스트·CI는 변경하지 않았다.

### 이전 이야기 카드 추가 작업

이야기 카드 12종과 공통 재연·환상을 구현했다. 기존 시작 덱은 그대로이며 새 카드들은 메르쿠리우스 카드 풀에 등록한다. 한영 카드 설명·재연 툴팁·이야기 수집·환상 파워 설명을 추가했다. 카드 그림과 파워 아이콘은 원작 임시 이미지를 참조하며 전용 아트는 아직 제작하지 않았다. 이번 추가 작업의 PCK 배포·Steam 설치·Git 업로드는 진행하지 않았다.

현재 C# 빌드는 경고·오류 0건이다. 임시 네이티브 환경에서 효과 관찰 51건과 한영 카드 설명 포맷 관찰 24건, 총 75건의 성공 결과를 얻었다. 후보 제한·모드 풀 포함, 3종 중복 제거, 원래 비용·휘발성·영구 원본 미연결, 선택한 카드만 강화 유물 횟수 소모, 손 강화의 전투 한정, 천사 이야기의 기본 복사와 소멸 제거, 미지 이야기의 멀티 제한, 이야기 수집의 이전 사용 기록·자동 사용 제외·중첩별 영구 덱 추가를 포함한다. 어둠 이야기의 환상 2/3과 일반 저주 선택도 확인했다. 환상은 양방향 다단·광역 공격의 타격별 상한 1 및 공격당 소비 1, 0·음수 피해 무시, 원래 피해 1과 방어도로 막은 양수 피해의 소비, 턴 종료 유지, 비공격 체력 손실 제외, 마지막 중첩 제거 후 정상 피해 복귀를 확인했다. 설명 관찰은 12종 각각의 기본·강화 문구를 두 언어에서 확인했다.

이 관찰은 정식 인수 테스트가 아니다. 원작의 임시 선택기와 합성 사용 기록을 활용했으며 실제 UI 조작·멀티 네트워크·전투 승리 전체 흐름은 실행하지 않았다. 첫 샌드박스 실행은 Windows 루트 인증서 저장소 읽기 오류가 있었으나, 이후 로컬 .NET 환경을 명시한 재실행은 엔진 오류 없이 종료 코드 0을 확인했다. 어둠 이야기·환상을 추가한 뒤의 최종 확대 관찰도 종료 코드 0과 75건 성공을 확인했다. 정식 테스트·CI는 변경하지 않았다.

전체 추적 참조 검사는 기존 미추적 그림·메르쿠리우스 문서·프리셋에 대한 15건으로 실패했다. 링크 대상 파일은 로컬에 존재하지만 Git에 아직 등록되지 않은 작업 파일이다. 검사 우회나 기존 작업 삭제는 하지 않았다.

### 이전 유물 작업

유물 5종과 조율 선택지 3종을 구현하고, 시작 유물 및 오로바스 교체에 연결했다. 한영 설명·선택 문구·세계의 기억의 조율 툴팁을 추가했다. 빌드는 경고·오류 0건이며 PCK 내보내기도 완료했다.

임시 네이티브 실행 환경에서 43건을 확인했다. 첫 손패의 사용불가·휘발성 교체, 재교체 방지, 민첩과 무관한 방어도 12, 초기 셔플 제외 및 전투별 초기화, 휘발성 카드의 두 소멸 원인과 방어도 무시 체력 감소, 적이 없는 경우, 조율의 세 선택지·카드 이동 범위, 첫 턴 조율 생략, 샛별의 다음 드로우 준비·에너지 지급·빈 더미 처리, 오로바스 교체, 양 언어의 원작 설명 포매터를 포함한다. 분리 실행 환경에서는 원래 BaseLib가 시작 시 수행하는 모드 등록을 재현했다.

별도 PCK 로드에서는 유물 텍스처 15개와 이동한 캐릭터 UI 텍스처 6개, 양 언어의 유물·선택지 문구를 확인했다. 이는 정식 인수 테스트가 아니며 정식 테스트·CI는 변경하지 않았다. 실제 게임 UI에서의 선택 조작, 멀티플레이 네트워크, 기존 저장 이전은 검증하지 않았다. Steam 설치본과 Git 원격은 이번에 변경하지 않았다.
