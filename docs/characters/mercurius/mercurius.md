# 메르쿠리우스 (Mercurius)

메르쿠리우스(Mercurius)의 기본 구성, 전용 유물, 핵심 키워드·카드 확정 규칙 및 원작 연동 제약을 정리한 문서다.

## 기본 정보 및 전용 유물

- **기본 체력:** 70
- **시작 덱 (10장):** 낡은 만돌린 1장, 환영 대역 1장, 메르쿠리우스 소속 기본 타격 4장, 메르쿠리우스 소속 기본 수비 4장
- **시작 유물:** 용의 이정표
- **카드 풀 구성:** 캐릭터 카드 81종(전용 기본 타격·수비 포함)과 효과 내부 전용 조율 선택지 3종, 전용 유물 5종.

| 유물 | 구분 | 확정 효과 |
|---|---|---|
| 용의 이정표 | 시작 | 첫 턴 기본 드로우 후 손의 사용불가 또는 휘발성 카드를 한 번에 버리고, 같은 장수를 뽑는다. 새로 뽑은 카드는 재검사하지 않는다. |
| 세계의 기억 | 강화 시작 | 용의 이정표의 첫 턴 효과를 유지한다. 두 번째 이후 자신의 매 턴 기본 드로우 후 조율한다. |
| 방호의 결속 | 일반 | 전투마다 처음 실제로 재셔플한 뒤 방어도 12를 얻는다. 전투 준비 중 초기 덱 무작위화는 제외한다. |
| 불꽃 두루마리 | 고급 | 자신이 가진 휘발성 카드가 소멸할 때 무작위로 타격 가능한 적 하나가 체력 7을 잃는다. 카드 효과로 소멸한 경우도 포함한다. |
| 샛별 | 희귀 | 첫 턴 기본 드로우 후 뽑을 더미에서 카드 1장을 골라 맨 위에 놓고 에너지 1을 얻는다. 선택한 카드를 즉시 뽑지는 않는다. 뽑을 더미가 비어도 에너지는 얻는다. |

용의 이정표는 오로바스의 손의 시작 유물 교체에 세계의 기억으로 연결한다. 두 유물은 별도의 시작 유물 보상으로 동시에 지급하지 않는다.

## 조율

조율은 지식의 악마처럼 선택지 카드 세 장을 표시해 하나를 고른다.

1. 손의 카드 1장을 뽑을 더미 맨 위에 놓는다.
2. 버린 더미의 카드 1장을 뽑을 더미 맨 위에 놓는다.
3. 버린 더미의 모든 카드를 뽑을 더미에 넣고 함께 섞는다.

앞의 두 선택지는 선택한 카드만 이동시키며 셔플을 발동시키지 않는다. 세 번째는 실제 재셔플이므로 방호의 결속 등 셔플 효과와 연계된다. 세 선택지는 항상 표시하며, 선택한 대상 더미가 비었다면 카드 이동은 일어나지 않는다. 손·버린 더미에서 원하는 장수 전체를 고르는 방식은 사용하지 않는다. 선택지 카드는 전투 중 조율 UI용이며 시작 덱·일반 보상으로 지급하지 않는다.

## 재연

재연은 이야기 테마의 방향을 카드 생성으로 표현하는 키워드다. 기본적으로 다른 캐릭터 또는 무색의 조건에 맞는 서로 다른 카드 3장을 무작위로 제시하고, 그중 하나를 선택해 휘발성을 부여한 전투용 생성본으로 손에 추가한다. 영구 덱 추가나 다른 후보 출처는 개별 카드에 명시한다.

| 항목 | 확정 규칙 |
|---|---|
| 후보 출처 | 자신이 아닌 다른 캐릭터의 일반 카드 풀 및 무색 카드 풀. 레아르타·알테아 등 모드 캐릭터도 포함한다. |
| 타입·희귀도 | 일반·고급·희귀의 공격 또는 스킬만 허용한다. 기본 타격·수비, 파워, 토큰, 저주, 상태이상, 퀘스트 및 특별 카드는 제시하지 않는다. |
| 획득 경로 | 일반 카드 풀을 기준으로 한다. 고대의 존재·이벤트 전용 카드는 제외한다. |
| 생성 상태 | 미강화·원래 비용이 기본이다. 강화된 생성본은 한 번 강화하며, 영구 덱 원본의 강화·인챈트·비용 변경은 복사하지 않는다. 비용 무료화·강화는 개별 카드에 명시한다. |
| 추가 특성 | 선택해 얻은 카드에 휘발성을 부여한다. 이미 휘발성이 있다면 중복 부여하지 않는다. 소멸은 별도로 추가하지 않는다. 원래 카드가 가진 다른 특성은 유지한다. |
| 영구 이득 제외 | 최대 체력·골드 획득, 영구 덱의 유리한 변경, 영구 카드 강화·성장·인챈트 등 전투를 지연해 누적할 수 있는 이득을 주는 카드는 제외한다. |
| 회복·포션 제외 | 체력 회복이나 포션 획득 효과를 가진 카드도 후보에서 제외한다. |

휘발성은 손에 남겼을 때의 소멸이며, 사용 직후 반드시 소멸한다는 뜻이 아니다. 따라서 사용 후 버린 더미로 간 카드가 같은 전투에서 다시 돌아와도 영구 이득을 반복 획득하지 못해야 한다. 단순히 휘발성만 붙였다는 이유로 포식 등의 영구 이득 카드를 허용하지 않는다.

반대로 전투 안에서만 성장하거나 이득을 얻고 전투 종료 시 사라지는 효과는 영구 이득이라는 이유만으로 배제하지 않는다. 생성본을 영구 덱 원본과 연결하지 않는 것이 전제다. 원작 생성 금지 설정, 해금 상태 및 싱글/멀티 전용 제한은 재연에서도 존중한다. 후보의 실제 동작을 검토하지 않은 모드 카드는 안전하다고 가정해 자동 편입하지 않는다.

- **예외 및 경계 조건:** 어둠 이야기는 저주 타입·희귀도 제한의 예외, 천사 이야기는 자기 캐릭터 출처 제한의 예외다. 천사·미지 이야기의 영구 덱 참조도 나머지 재연 안전 제한은 유지하므로 기본 카드·파워·특별 카드는 후보가 아니다. 같은 종류가 여러 장 있어도 선택지 수를 늘리지 않는다. 후보가 3종보다 적으면 있는 종류만 제시하고, 0종이면 재연만 불발한다.

## 핵심 메커니즘 및 카드 확정 규칙

- **환상:** 받거나 주는 공격 피해를 1로 제한하는 독립 효과다. 턴 종료로 자동 감소하지 않으며, 주거나 받는 양수 공격마다 1 소비하고 0 이하 피해는 무시한다. 게임의 공격 처리 단위로 세므로 다단·광역도 한 공격당 1회분을 소비하고 각 타격 피해를 1로 제한한다. 방어도로 막은 양수 공격도 포함하며, 비공격 체력 손실·독·반격 피해 등은 제한하거나 소비하지 않는다.
- **환상 감소 반응 (섞여들기·환상의 살해자):** 감소 사건 횟수가 아닌 실제 잃은 수치만큼 발동한다. 수치보다 큰 음수 변경은 남아 있던 수치로 제한하고, 직접 제거하면 남은 수치만큼 발동하되 마지막 중첩이 0이 되어 제거될 때 중복 발동하지 않는다. 섞여들기는 잃은 환상 1당 중첩 수만큼 뽑는다. 환상의 살해자는 대상 적의 체력을 감소시키며, 버린 더미에 있을 때만 손으로 이동하므로 이미 손에 있으면 추가 이동하지 않는다.
- **노래:** 실제 드로우에만 발동한다. 생성·회수로 손에 들어올 때와 손에서 사용할 때는 효과가 없다. 사용 비용은 1이며 사용 후 보통 버려지고, 손에 남으면 휘발성으로 소멸한다.
- **결말:** 극적인·비참한·신비한·행복한·완벽한 결말 5종 모두 턴 시작·카드 효과·밑장 드로우 등 **실제 드로우마다** 제한 없이 강화한다. 초기 셔플·재셔플·맨 위 배치·회수·생성으로 손에 들어오는 것 자체는 강화 조건이 아니다. 영구 덱 원본의 강화는 유지하되 전투 중 추가 강화는 영구 덱을 변경하지 않는다. 완벽한 결말은 비용 0의 희귀 파워로, 사용 시 한 번만 현재 수치의 에너지를 얻고 일반 파워처럼 전투 카드에서 제거되며 지속 파워는 부여하지 않는다(미강화 상태에서도 설명에 에너지 0을 명시).
- **권능:** 손에 해당 카드만 있을 때 적용한다. 관통하는 빛은 조건 충족 시 비용을 0으로 표시하고, 빛나는 혼은 방어도 획득을 총 2(3)회 수행하며, 에스트리드의 천둥은 피해만 2회 주고 취약은 1회 부여한다.
- **조율 완료 연동 (공격적 조롱·오롯한 존재·함께 걸어나갈 때):** 조율 완료는 빈 더미를 선택해 이동이 없어도 성립한다. 공격적 조롱은 그 턴 동안만 비용이 0이 되며 다음 턴에 조건을 다시 판단한다. 오롯한 존재는 조율과 실제 셔플마다 방어도 3(4)를 얻고 중첩을 합산한다(조율 3번 선택지로 셔플하면 두 사건이므로 2회 발동, 초기 무작위화 제외, 민첩 미적용). 함께 걸어나갈 때는 멀티 전용이며 빈 더미 선택을 포함한 조율 완료마다 소유자 외 플레이어에게 중첩 수만큼 실제 드로우를 적용한다.
- **지도 / 분위기 조절:** 지도는 그 턴의 일반 버림 결과만 뽑을 더미 맨 위로 바꾼다(소멸·파워·복제본의 원래 우선순위 유지, 첫 사용 지도 자신에게는 미적용). 분위기 조절은 휘발성 소멸과 턴 종료 손패 버리기 전에 중첩당 1장씩 선택해 옮긴다.
- **다른 색 판정 (전설의 일격·화염 채찍·옛날 옛적에·이야기의 현신):** 다른 색은 소유 캐릭터의 카드 풀과 다른 풀에 속하는 카드로, 무색·저주·상태이상도 포함한다(재연 안전 제한과 별개). 전설의 일격은 손의 다른 색 카드 N장을 모두 버리고 기본 1회+N회 공격한다. 화염 채찍은 이번 턴 다음 다른 색 카드 사용 후 피해 효과만 1회 반복하며 카드 사용·인챈트는 재실행하지 않는다(무작위 적 재선정, 여러 대기는 각각 발동). 옛날 옛적에는 다음 다른 색 카드에 중첩당 추가 사용 1회를 부여하며 비용은 1회만 지불하고 원작 반복 경로로 처리한 뒤 턴 종료 시 남은 효과를 제거한다. 이야기의 현신은 비용 3의 희귀 파워로 기본 휘발성·강화 시 휘발성을 제거하고 보존을 얻으며, 다른 색 카드 사용마다 중첩당 힘·민첩 1을 얻는다.
- **유아독존 / 환영 복제:** 유아독존은 멀티 전용이며 다른 플레이어가 생성한 카드만 중첩 수만큼 복사한다. 강화·비용 변경·인챈트를 계승하고 휘발성을 추가하며 영구 덱 원본과 연결하지 않고, 유아독존 복사본이 다른 유아독존을 연쇄 발동시키지 않는다. 환영 복제는 플레이어 턴·적 턴 각각 소유자가 실제로 처음 사용하는 카드의 휘발성 복사본을 중첩 수만큼 손에 추가한다(자동 사용 포함, 강화·비용·인챈트 계승, 영구 덱 미연결, 같은 카드 반복 사용 시 첫 사용만 집계, 턴 중 두 번째 사용 이후 부여해도 첫 사용 조건 미재시작).
- **광란의 노래:** 모든 적의 현재 공격 의도 피해를 다단 합산한다(비공격 적 0). 노래 소유자를 대상으로 한 피해 수정 기준으로 계산하며 멀티 플레이어 수로 중복 곱하지 않는다. 기본은 무작위 적 1명, 강화는 모든 적이 합계만큼 체력을 잃으며 방어도·힘·약화 등 일반 공격 피해 수정의 영향을 다시 받지 않는다.
- **치유의 손 / 선택하는 운명 / 사자와의 대화 / 손 안의 운명:** 치유의 손은 체력 회복 카드가 아니며 휘발성 부여만 수행한다(기본 1장, 강화 시 0장 이상 원하는 장수). 선택하는 운명은 처음 뽑은 카드와 다른 타입을 처음 뽑은 시점에 종료하며 그 카드도 손에 남기고, 더 뽑을 수 없으면 종료한다(강화 시 소멸 제거). 사자와의 대화는 소멸 더미에서 X(강화 X+1)장을 선택해 뽑을 더미 맨 위로 옮기며 원작 Chemical X 등 X 수정을 적용한다(0장이면 선택창 미표시). 손 안의 운명은 뽑은 카드의 현재 표시 비용만큼 에너지를 얻고 X 비용과 음수 비용은 0으로 센다.
- **손기술 / 밑장빼기 / 카운팅 / 으뜸패:** 손기술은 손의 카드 1(2)장을 뽑을 더미 맨 아래에 놓고 1(2)장을 뽑는다(버리기·셔플 아님). 밑장빼기는 실제 드로우를 수행하므로 노래·드로우 기록·드로우 금지가 적용된다. 카운팅은 손 전체를 아래에 놓고 놓은 장수만큼 뽑는다(밑장빼기·카운팅 모두 기본 소멸·강화 시 소멸 제거). 으뜸패는 손의 1장을 남기고 나머지 손의 카드를 뽑을 더미에 섞는다(버린 더미 미합산, 실제 셔플 효과·새김 발동).
- **정신의 창 / 메아리치는 노래 / 권능의 말:** 정신의 창은 원작 공격 실행 후 방어도를 뚫고 실제 체력에 준 피해(`UnblockedDamage`)만큼 추가 비공격 체력 손실을 준다. 메아리치는 노래는 소유자·턴 단위 2배 누적 배율(1배·2배·4배…)을 같은 이름의 모든 카드가 공유하며 턴 종료 시 초기화한다(표현 가능한 정수 피해 범위). 권능의 말은 공격 후 살아 있는 대상의 현재 HP가 100 이하일 때만 원작 기절을 적용한다.
- **신비의 비밀 / 운명의 종점 / 점복:** 신비의 비밀은 드로우한 카드가 휘발성이면 원작 자동 사용 경로를 호출하되 사용할 수 없는 카드를 강제 실행하지 않는다. 운명의 종점은 매 반복마다 무작위 적을 다시 고르고 실제 뽑은 카드가 휘발성일 때만 반복한다(뽑을 수 없으면 종료). 점복은 뽑은 시점의 휘발성 여부를 보관해 소멸 후 에너지를 지급한다.
- **무형의 날개 / 오리무중 / 무한의 음색 / 안식의 노래:** 무형의 날개는 사용 시작 시 마지막 손패 여부를 보관해 다른 사용 후 드로우 훅 순서의 영향을 받지 않는다. 오리무중은 휘발성 소멸 처리 전에 손을 확인한다. 무한의 음색은 강화 시 선천성을 얻는다. 안식의 노래는 멀티 전용으로 모든 살아 있는 플레이어에게 원작 재생을 부여하며, 반복 회복 효과이므로 일반 전투 생성 후보에서 제외한다.
- **영구 이득 파워 (이야기 수집가·새겨진 기억·여행의 추억):** 세 파워 모두 영구 이득 카드이므로 일반 전투 생성 후보에서 제외한다.
  - **이야기 수집가:** 자신이 직접 사용한 다른 색 카드만 세고 자동 사용은 제외하며, 파워를 내기 전의 전투 사용 기록도 포함한다.
  - **새겨진 기억:** 중첩마다 해당 전투의 카드 보상 중 아직 인챈트되지 않고 네 인챈트(새김·안성맞춤·신속 1·안정)를 모두 받을 수 있는 무작위 카드 1장에 동등 확률로 인챈트를 부여한다(유효 대상이 없으면 불발, 부여된 인챈트는 영구 덱에 유지). 새김은 초기 셔플과 전투 중 셔플 모두 맨 아래 배치이며, 안성맞춤·신속·안정은 원작 인챈트 동작을 따른다.
  - **여행의 추억:** 승리 후 중첩마다 카드 보상 1개를 추가해 다른 캐릭터와 정확한 무색 풀의 일반·고급·희귀 공격/스킬/파워 3종을 제시한다. 재연과 달리 파워·회복·영구 이득 카드도 허용하고 휘발성을 추가하지 않으며, 선택한 카드는 원작 카드 보상의 수정·강화 확률·저장·재굴림 경로를 따라 영구 덱에 추가된다.

## 기존 게임 동작과의 대응

확인한 원작 DLL은 `sts2.dll` 제품 버전 `0.1.0+59260271157f76a2896f0eab5bc6ea1245d8b314`다.

- **유물·조율·셔플:**
  - `GamblingChip.AfterPlayerTurnStart`와 `CardCmd.DiscardAndDraw` 경로로 첫 턴 기본 손패 교체(용의 이정표)를 처리하며 교체 대상은 실행 전 한 번만 확정한다.
  - `KnowledgeDemon.ChooseCurse`와 `CardSelectCmd.FromChooseACardScreen`으로 조율의 세 카드 선택 UI와 동기화를 재사용하고, 실제 효과는 세 전용 선택지 모델이 각각 소유한다.
  - `TheAbacus.AfterShuffle` 및 `CardPileCmd.Shuffle`은 실제 재셔플 뒤에 발동하며 초기 `CardPile.RandomizeOrderInternal`은 이 훅을 호출하지 않는다. 방호의 결속과 오롯한 존재의 방어도는 비공격 수치로 처리해 민첩으로 늘리지 않는다. 오롯한 존재는 조율 완료 통지와 원작 `AfterShuffle`을 별도로 받아 임의로 합치지 않는다.
  - 원작 셔플 명령은 버린 더미 전체를 합치므로 으뜸패에 그대로 쓰지 않고, 뽑을 더미만 원작 셔플 RNG·순서 변경 훅으로 섞은 뒤 실제 `AfterShuffle`을 발행한다.
  - `ForgottenSoul.AfterCardExhausted`와 `PoisonPower`의 체력 감소 경로를 참고해 불꽃 두루마리는 소멸 원인과 무관하게 휘발성 키워드를 확인하고, 전투 대상 전용 RNG로 적을 골라 방어도 무시·비공격 피해 경로를 사용한다.
- **재연·전투 보상·인챈트:**
  - `CardFactory.GetDistinctForCombat`으로 플레이어 수·전투 생성 금지 필터·중복 없는 표본 추출을 처리하고 타입·희귀도 허용 목록은 재연이 추가한다. `Discovery.OnPlay`의 선택 UI만 재사용하며 무료 비용 효과는 가져오지 않는다.
  - `EventCardPool.IsColorless`도 참이므로 `ColorlessCardPool`을 직접 참조한다.
  - `Feed`, `HandOfGreed`, `NotYet`, `Alchemize`, `HiddenGem`, `TheHunt`의 원작 생성 금지를 유지하고 회복하는 `Spur`를 추가로 제외한다. 외부 모드의 미검토 풀은 자동 허용하지 않는다.
  - `GeneticAlgorithm.OnPlay`·`TheScythe.OnPlay`의 영구 성장은 `DeckVersion`이 있을 때만 발생하므로, 재연은 `CanonicalInstance`에서 새 전투본을 만들고 영구 덱 원본과 연결하지 않아 전투 중 성장만 남긴다.
  - 강화된 선택지 미리보기는 `UpgradeInternal`·`FinalizeUpgradeInternal`을 사용하고, 실제 선택한 카드 1장에만 `CardCmd.Upgrade`를 호출해 강화 횟수 연동 유물이 미리보기 3장에 소모되지 않게 한다. `Armaments.OnPlay`처럼 손 선택 후 `CardCmd.Upgrade`로 전투 카드만 강화하며 약화·취약·별·소환·재생(`RegenPower`)·기절(`CreatureCmd.Stun`)은 원작 타입을 그대로 사용한다.
  - `Swift`, `PerfectFit`, `Steady`는 원작 타입을 그대로 사용한다. `Imbued`는 초기 맨 아래 배치 외에 자동 사용 동작이 있어 새김으로 재사용하지 않는다.
  - `CombatManager.WinCombat`은 `AfterCombatEnd` → 파워 제거 → `AfterCombatVictory` 순서다. 이야기 수집가는 파워가 남아 있는 `AfterCombatEnd`에서 전체 `History.CardPlaysStarted`를 읽고 선택을 기다린 뒤 `CardPileCmd.Add(..., Deck)`로 추가한다(일반 보상 재굴림이 후보 조건을 바꾸지 않도록 직접 선택 UI 사용).
  - 여행의 추억도 파워가 남아 있는 `AfterCombatEnd`에서 `CombatRoom.AddExtraReward`를 사용하며, 직렬화할 수 없는 임의 카드 목록·필터 델리게이트 대신 실제 다른 캐릭터·무색 풀 ID를 담은 `CardCreationOptions`와 일반 전투 희귀도 확률로 구성한다.
  - `AfterCombatEnd` 이후 파워 제거 뒤에 `RewardsSet.GenerateWithoutOffering`가 보상 옵션을 만든다. 새겨진 기억은 전투 방·플레이어별 중첩을 약한 참조에 보관해 해당 보상 세트 생성 완료 후 한 번만 소비하며, 각 플레이어의 원작 보상 RNG(`PlayerRng.Rewards`)를 사용한다. 보상 재굴림은 보상 세트를 거치지 않고 `CardReward.Populate`로 옵션을 바꾸므로, 처음 부여된 각 카드 보상의 부여 횟수를 `AfterGenerated`에 연결해 재생성 옵션에도 원작 `CardCmd.Enchant`와 저장 경로로 적용한다.
- **환상·반복·드로우·결말:**
  - 원작 `IllusionPower`는 몬스터 부활용이라 플레이어에 적용할 수 없고, `IntangiblePower`는 받는 피해만 제한한다. 환상은 `ModifyDamageCap`에서 양방향 공격 피해 상한을 1로 적용하고, `AfterAttack`에서 방어도로 막힌 피해를 포함한 `DamageResult.TotalDamage`가 양수일 때 1 감소하며, `AfterSideTurnEnd`를 구현하지 않아 턴 종료로 감소하지 않는다.
  - 환상은 `BeforePowerAmountChanged`에서 기존 수치를 보관하고 `AfterPowerAmountChanged`에서 실제 감소량을 계산하며, 직접 제거는 자기 `AfterRemoved`에서 처리한다. `MercuriusIllusionLossListener`가 버린 더미 회수와 드로우 두 구현에 감소 통보를 공유한다(별도 전역 파워 제거 패치 없음).
  - `ModifyCardPlayCount`·`AfterModifyingCardPlayCount`는 원작 Burst/Duplication 파워와 같은 반복 경로이므로 새로 부여한 재사용 효과가 부여 카드 자신에 즉시 소비되지 않는다.
  - 환영 복제는 원작 Echo Form처럼 `History.CardPlaysStarted`의 소유자·현재 턴·`IsFirstInSeries`를 기준으로 판단하되, 사용 중 신비의 비밀 등이 다른 카드를 자동 사용해도 첫 원본 카드를 놓치지 않도록 `BeforeCardPlayed`에서 첫 사용을 보관하고 `AfterCardPlayed`에서 복사한다(원작은 `BeforeCardPlayed` 다음에 시작 기록 추가).
  - `CardPileCmd.Draw`를 거쳐야 드로우 기록·노래·금지가 함께 작동한다. 밑장 드로우는 드로우가 금지되거나 손이 가득 찬 경우 순서를 바꾸지 않고, 유효할 때만 맨 아래 카드를 맨 위로 옮긴 뒤 원작 드로우 명령을 호출한다.
  - 결말은 카드 자신의 `AfterCardDrawn`에서 `card == this`일 때 `CardCmd.Upgrade`를 실행하므로 밑장 드로우를 포함한 모든 실제 드로우에서 동일하게 동작한다.

## 식별자와 저장 호환성

캐릭터 모델은 `Mercurius`(ID `STS2WD-MERCURIUS`), UI 경로는 `Sts2WD/images/charui/mercurius/`, 문장 프리셋은 `Sts2WD/character_text/mercurius.json`이며 아셀리게의 메르쿠리우스 전용 선물 대상도 이 타입에 연결한다. 이전 자리표시 ID(`STS2WD-CHARACTER_THREE`)로 진행하던 저장은 자동 이전하지 않으며, 기존 저장에 이미 들어 있는 원작 기본 타격·수비도 자동 변환하지 않는다. 카드 모델 ID는 시트 행 이동이나 표시명과 무관하게 유지한다(예: 공격 카드 옛날 옛적에는 `MercuriusAvatarOfStories`, 희귀 파워 이야기의 현신은 별도 `MercuriusIncarnationOfStories`). 리소스 경로와 아트 명세는 [아트 명세](mercurius-art.md)·[에셋 상태](mercurius-assets.md), 로컬 설치 범위는 [배포 기록](/docs/deployment-status.md)에서 확인한다.
