## Basic Strike Portrait

The applied portrait shows a compact medieval crossbow in three-quarter close-up, with a bolt leaving the rail toward the upper right. The wood stock, transverse steel bow limbs, connected string, and brass fittings read against a red and burgundy background. Native `StrikeIronclad` and `StrikeSilent` portraits guided composition and rendering. Use the [applied portrait](mercurius-assets.md#cards-and-power-icons) for the current card artwork.

## Relic production brief

Five separate relic icons are specified below as isolated object references, not a character appearance base. Use the original-game relic/potion sheet for compact silhouettes, broad values and small-scale readability only. Generate every object separately on true transparent alpha, without scenery, floors, shadows, UI or text; preserve the complete painting in size conversion. A few broad material planes should remain readable at 94 and 48 px.
