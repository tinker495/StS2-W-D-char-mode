# 메르쿠리우스 공식 전신 베이스

2026-10-31 사용자가 **색조 수정본 v7**을 base.png로 지정한 뒤, 다른 전신 베이스 규격에 맞춰 투명 여백과 인물 크기를 조정하도록 요청했다. [공식 base.png](../../base.png)는 로컬 제작 자료로 보관한 정사각 v7 원본의 그림을 보존한 **1024 × 1536 세로형**이다. 현재 외형·색상·구도는 공식 파일을 기준으로 한다. [제작 명세](art.md)와 [작업 이력](../../mercurius-history.md)에 결정과 적용 범위를 기록했다.

## 파일과 적용 범위

| 항목 | 현재 상태 |
|---|---|
| 공식 기준 이미지 | docs/characters/mercurius/base.png |
| 규격 | 1024 × 1536 PNG, RGBA; 알테아와 같은 크기, 레알타와 같은 2:3 비율 |
| 승인본 | 2026-10-31 색조 수정본 v7 및 사용자가 요청한 투명 여백 정리·인물 크기 조정 |
| 적용 방식 | 투명 외곽만 크롭한 뒤 비례 Fit 확대. 재생성·추가 색 보정 없음 |
| 구도 | 전신을 가로 중앙에 배치. 깃털부터 발끝까지 높이 1270 px로 캔버스 높이의 82.7% |
| 팔레트 | 따뜻한 아이보리·절제된 금색·차가운 남색, 자연스러운 피부·금발과 녹색/청록 포인트 |
| 런타임 | 공식 기준 이미지에만 반영. UI·전투 이미지·카드·애니메이션은 이번 작업에서 변경하지 않음 |
| 패키징·설치 | 이번 베이스 가공 작업에서 수행하지 않음 |

기존 런타임 상태는 [에셋 안내](../../mercurius-assets.md)와 [공통 배포 기록](../../../../deployment-status.md)이 관리한다. 이 베이스 승인만으로 새 UI·전투 출력이나 게임 내 크기 검증이 완료된 것은 아니다.

## 제작·검사 기록

| 항목 | 확인 결과 |
|---|---|
| 제작 입력 | 사용자가 첨부한 정사각 그림과 원작 Silent/Ironclad 색상 참고 |
| 생성 | 색조 수정본 제작 당시 기본 GPT Image 1회. 이번 규격 변환의 생성·보정 생성은 0회 |
| 승인 전 납품 변환 | 전체 1254 × 1254 생성 캔버스를 비례 Fit 축소해 1024 × 1024로 저장. 크롭·부분 확대·피사체 재배치 없음 |
| 세로 규격 변환 | 정사각 v7의 (x234, y29)에서 598 × 897 영역을 유지한 뒤, 저장소 asset-pipeline.ps1의 export / Fit으로 1024 × 1536 출력. 가로·세로 배율 모두 1024/598 ≈ 1.7124 |
| 여백 정리 보존 | 제거한 영역의 alpha > 0 픽셀 0개. 남긴 영역은 확대 전 모든 RGBA 채널이 원본과 동일 |
| 비례 확대 | HighQualityBicubic 보간 사용. 크기 변환에 따른 픽셀 재표본화 외 별도 색상·형태 편집 없음 |
| 공식 파일 보존 | 검토한 세로형 변환본과 base.png의 SHA-256 일치. 정사각 v7 원본은 별도로 유지 |
| 공식 SHA-256 | 80BCD50294D85E72BC50603256A515E756ABC4D625F02DCB1EBC262DEE3A14AA |
| 정사각 원본 SHA-256 | E1ABAA962257D16E7D7E6C5623B21435753BEF8EDD0D2A2648C79BC2FE62EB84 |
| 피사체 범위 | alpha > 8 기준 x84–940, y146–1415; 폭 약 83.7%, 높이 약 82.7% |
| 투명 여백 | 왼쪽 84 px, 위 146 px, 오른쪽 83 px, 아래 120 px; 최소 약 7.8% |
| 투명도 | RGBA 투명 배경 유지, 모서리 알파 모두 0 |
| 시각 확인 | 전체 변환본, 240 × 360 밝고 어두운 배경에서 알테아·레알타와 IndividualFit 비교, 정사각 원본과 SubjectFit 비교를 열어 확인 |

원본 대화 첨부의 로컬 파일이 없어 최초 색조 편집 전후의 선·형태를 픽셀 단위로 비교하지는 못했다. 사용자가 승인한 v7 그림을 현재 기준으로 삼는다. 이번 규격 변환에서는 정사각 v7 원본을 기준으로 여백 제거의 픽셀 보존을 확인했고, 최종 변환본에서 base.png로의 복사가 바이트 단위로 동일함을 확인했다.

이번 적용에서는 이미지 규격·투명도·여백·크롭 보존과 파일 동일성을 관찰했다. 정식 테스트·빌드·게임 내 검증은 실행하지 않았다. 비교판·프롬프트·임시 관찰 로그는 로컬 제작 자료이며 현재 기준을 이해하거나 다음 에셋을 만드는 데 필수 입력이 아니다.

## 샤프닝 비교 후보 — 미적용

2026-10-31 사용자의 요청으로 샤프닝 후보 v2를 별도 제작해 로컬 제작 자료로 보관했다. 현재 base.png를 유일한 입력으로 기본 GPT Image 편집 1회와 원본에서 다시 시작한 보정 1회를 수행했다. 윤곽·의상 테두리·플루트가 더 또렷해졌으나, 생성형 보정으로 얼굴선·깃털·장식 일부에는 작은 변화가 남는다. 기존 공식 베이스와 런타임은 변경하지 않았다.
