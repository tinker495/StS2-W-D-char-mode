# 메르쿠리우스 공식 전신 베이스

[base.png](../../base.png)가 현재 외형 기준이다. 사용자 승인 v7의 색상·포즈를 유지하고, 명시적으로 허용한 투명 여백 정리와 비례 확대를 적용했다. [외형 명세](art.md)를 따른다.

| 항목 | 상태 |
|---|---|
| 파일 | `docs/characters/mercurius/base.png` |
| 규격 | 1024 × 1536 RGBA, 투명 배경 |
| 구도 | 전신 중앙 배치, 깃털부터 발끝까지 캔버스 높이의 약 82.7% |
| 변환 | 완전히 투명한 외곽만 제거한 뒤 비례 Fit. 그림 일부 제거·재생성·재색칠 없음 |
| 런타임 | 전체 그림을 축소해 전투·휴식·상점에서 공용 사용. [UI·전신 매핑](../ui/assets.md) 참조 |

전체 그림과 240 × 360 밝고 어두운 배경에서 실루엣·접점·여백을 확인했다. 패키징·설치·게임 검증 범위는 [공통 배포 기록](../../../../deployment-status.md)이 관리한다.
