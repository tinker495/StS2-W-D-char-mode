# 메르쿠리우스 선택 배경 적용 상태

2026-10-31 사용자가 **B 버전 + 수정본**을 채택하여 차분한 눈매의 선택 배경을 정식 리소스에 적용했다. 장면과 참조 역할은 [제작 명세](art.md), 나머지 파일은 [UI·전신 상태](../ui/assets.md)를 따른다.

| 항목 | 상태 |
|---|---|
| 정식 파일 | `Sts2WD/images/charui/mercurius/char_select_bg.png` |
| 규격 | 1920 × 1080 PNG, 전체 픽셀 불투명 |
| 모델 연결 | `Mercurius.CustomCharacterSelectBg` |
| 장면 | `Sts2WD/scenes/mercurius/char_select_bg_mercurius.tscn` |
| 표시 | 전체 영역 Control 아래 TextureRect, `KEEP_ASPECT_CENTERED` (`stretch_mode = 5`) |
| 변환 | 1672 × 941 전체 그림의 비례 Fit, 불투명 남색으로 반올림 가장자리 처리, 크롭 없음 |
| 적용 | 검토한 차분한 눈매 수정본과 바이트 동일. 적용 시 추가 생성·보정 없음 |

플루트 연주와 청록색 흐름을 연결한 배경이다. 설명문 뒤의 밝은 금색 효과와 작은 입자를 줄인 뒤, 사용자의 후속 요청으로 윗눈꺼풀을 조금 낮추고 눈썹을 편안하게 조정했다. 녹색 눈·시선·연주 동작과 전체 배치는 시각 비교에서 유지됐으며, 생성형 편집 특성상 작은 선·색 변화가 남는다. 그 수정본이 현재 채택본이다.

전체 원본과 원작의 640 × 360 비교, 1920 × 1080 UI 영역 합성, 눈매 수정 전후를 확인했다. 얼굴과 양손의 연주 접점은 설명 영역 밖에 남으며, 플루트 끝과 소매 일부는 설명 영역에 들어간다. 하단 옷자락은 승천·타일 영역과 겹친다. UI 합성은 저장소의 근사 배치를 사용했으며 실제 설명문·버튼 마스크·게임 화면 검증은 아니다.

현재 정식 리소스와 이 문서가 적용 기준이며, 이전 후보·비교판·프롬프트는 로컬 제작 자료다. 빌드·PCK 로딩과 설치 여부는 [공통 배포 기록](../../../../deployment-status.md#2026-10-31-메르쿠리우스-branch-b-패키징)에 있다.
