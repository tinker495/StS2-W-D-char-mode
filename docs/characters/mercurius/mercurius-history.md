# 메르쿠리우스 아트 작업 이력

## 2026-10-31 — Branch B의 B 타일·차분한 눈매 수정본 채택

사용자가 “B 버전 + 수정본 채택.”으로 선택을 확정했다. 왼쪽을 바라보며 턱을 살짝 든 B 타일과, 초상화·지도 마커·선택 배경의 차분한 눈매 수정본을 적용했다. 양눈의 윗눈꺼풀과 눈썹의 긴장을 줄인 방향이다. 잠금 타일·초상화 윤곽선은 선택된 이미지의 알파를 따른다.

공식 베이스 전체를 축소한 공용 전신과 금색·청록 에너지 아이콘을 포함해 정식 PNG 9종, 전투·휴식·상점·선택 배경 장면 4개를 연결했다. 베이스 자체는 교체하지 않았다. 파일·장면 매핑은 [UI·전신 상태](visuals/ui/assets.md), 선택 장면은 [배경 상태](visuals/selection/assets.md), 패키징·검증·설치는 [공통 기록](../../deployment-status.md#2026-10-31-메르쿠리우스-branch-b-패키징)이 관리한다.

## 2026-10-31 — 다른 전신 베이스에 맞춘 세로 규격 변환

사용자가 다른 base.png 규격에 맞춘 가공을 요청하고, 투명 여백을 정리해 인물 크기도 맞추는 방식을 선택했다. 알테아의 1024 × 1536과 레알타의 1152 × 1728이 모두 2:3 세로형임을 확인한 뒤, 알테아와 같은 1024 × 1536 RGBA로 변환했다.

승인된 정사각 v7에서 완전히 투명한 외곽만 잘라내고 비례 확대하여 인물 높이를 알테아와 같은 약 82.7%로 맞췄다. 제거된 비투명 픽셀은 0개이며 색상·포즈·신체 비율을 보존했다. 원본 v7은 별도로 유지한다. 재생성·추가 색 보정·런타임 변경은 수행하지 않았다.

## 2026-10-31 — 정사각 색조 수정본 v7 확정

사용자가 새로 첨부한 정사각 이미지의 색조를 원작에 맞추도록 요청했다. 넓은 여백과 작은 전신 배치를 유지하는 방향으로 아이보리·금색·남색의 구분과 따뜻한 밝은 톤·차가운 그림자 톤을 정리했다. 원작 Silent/Ironclad 이미지는 색상 참고로 사용했다.

사용자가 이 결과를 base.png로 지정하여 당시 1024 × 1024 RGBA 납품본을 추가 수정 없이 복사했다. 이 선택은 이전 v2 베이스를 대체한다. 외형·색상은 v7을 유지하며, 이후 위의 사용자 요청으로 캔버스 규격과 투명 여백을 변경했다. 런타임 UI·전투 이미지와 게임 설치는 이번 승인에 포함하지 않는다.

## 2026-10-30 — 전신 베이스 v2 확정

참조 4장을 바탕으로 깃털 모자, 금발과 녹색 눈, 아이보리·남색·금색 의상, 플루트 연주 자세의 전신 후보를 제작했다. v2는 첫 후보의 장식을 정리하면서 정교한 얼굴과 부드러운 의상 표현을 유지한 안이다.

원작과의 화풍 차이를 줄이는 v3, v2/v3 중간안인 v4, v2의 색감만 조정한 별도 안도 비교했다. 사용자가 한때 v4를 선택했으나, 당시 최종 지시를 **“v2 를 base 로.”**로 변경했다. 이에 따라 원래 v2의 그림과 색상을 유지한 채 공식 base.png를 v2로 교체했다. 이 기록은 10월 30일의 선택이며, 이후 위의 v7 승인으로 갱신됐다.

현재 외형은 [제작 명세](visuals/base/art.md), 파일 규격과 승인·적용 범위는 [에셋 상태](visuals/base/assets.md)를 따른다. 이 결정은 공식 기준 이미지의 확정이며, 런타임 에셋 생성이나 게임 설치까지 포함하지 않는다.
