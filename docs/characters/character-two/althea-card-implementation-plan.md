# Althea 카드 구현 현황

2026-10-23, [공유 카드 시트](https://docs.google.com/spreadsheets/d/1rwlbeGbN32cwy-rOZWJzCIR_Rhyx5rmiezInGhioEq0/edit)의 `Althea` 탭과 [설계 합의](../../althea-design.md)를 바탕으로 초기 카드 구성을 구현했다. 기준은 2026-10-23에 다시 읽은 시트와 같은 날 사용자가 확정한 이름·효과 해석이다. 이후 시트 변경은 다시 비교해야 한다.

## 구현 범위

| 구성 | 종류 |
|---|---:|
| 시트 기본 카드 | 1 |
| 재편 토큰·망령 | 5 |
| 일반 | 21 |
| 고급 | 30 |
| 작성된 희귀 | 21 |
| 고대 | 2 |
| 시트 합계 | 80 |
| 전용 기본 타격·방어 | 2 |
| 실제 카드 모델 합계 | 82 |
| 관련 파워 | 26 |
| 전용 유물 | 5 |

시트에서 효과가 작성된 80종을 모두 반영했다. 75종 구현 이후 5종이 늘었다. 토큰·기본·고대 카드는 일반 생성 대상에서 제외한다.

- 내부 `CharacterTwo` ID를 유지하고 표시 이름을 Althea로 변경했다. 시작 덱은 **분노의 타격 1 / 타격 5 / 방어 4**, 시작 유물은 **윌드**다.
- 승인한 검붉은 에너지 아이콘과 붉은 상단→검푸른 하단 카드 몸체를 연결했다. 기본 희귀도 리본·초상화 테두리와 고대 카드 표현은 유지한다. 전투 하단 에너지 카운터는 기존 캐릭터 임시 표현을 사용한다.
- 카드 초상화·파워 아이콘·유물 아이콘은 기본 게임 그림을 임시 사용한다. 전용 일러스트가 완성된 상태는 아니다.
- 한국어·영어 카드 설명, 강화 변화, 선택 문구, 키워드와 파워·유물 설명을 추가했다.

## 2026-10-23 추가·변경

- **최신 시트 추가 5종:** 영혼 장막, 저주 장악, 바다 가르기, 최후의 일격, 투사의 형상. 영혼 장막·저주 장악·최후의 일격은 기본 게임의 멀티 전용 제약을 사용한다. 카드 모델은 82종, 파워는 26종이다.
- **토큰·기존 카드 후속 조정:** 시아르쿤 피해 14(18), 순수한 의지 소멸 추가, 집념의 타격 피해 12(16) 및 손의 다른 저주 필요, 필사의 타격 30(44), 치솟는 광기 4(6)드로우, 상어의 이빨 7(11), 투쟁 6(8), 상어의 자세 비용 1·2(3)드로우, 사자의 자세 힘 3. 겐 모르피 클라드는 매 타격의 대상을 무작위로 정한다.
- **군도의 무예 확장:** 공격뿐 아니라 이번 전투에서 재편된 카드가 실제 소비한 에너지도 센다. 이전 턴에 재편한 카드도 포함하며, 재편된 공격이라고 두 번 세지 않는다. 임의 생성한 같은 종류의 토큰은 재편 이력이 없으면 일반 타입 기준을 따른다.
- **바다 가르기:** 사용자 확정에 따라 현재 버린 더미·소멸 더미의 저주 장수만큼 비용 10이 감소한다. 해당 더미에서 저주가 빠져나오면 비용이 다시 오르며 0 아래로 내려가지 않는다. 유물로 저주 취급되는 카드도 포함한다.
- **저주 장악:** 사용자 확정에 따라 다른 모든 플레이어의 손·뽑을 더미·버린 더미에서 현재 저주 취급 카드를 가져온다. 소멸 더미와 영구 덱은 제외한다. 전투 카드 인스턴스와 강화·비용·인챈트·덱 원본 연결은 유지하고 소유자와 전투 더미만 바꾼다. 이는 소멸·새 카드 생성·새 전투 진입이 아니다. 이동 후 저주 판정에는 새 소유자의 유물이 적용된다.
- **영혼 장막·망령:** 각 플레이어가 소유하는 망령 2장을 각각 손에 추가한다. 망령의 소멸 드로우는 캐릭터 훅에서 카드 자신으로 옮겨 다른 캐릭터가 받아도 작동한다.
- **최후의 일격·투사의 형상:** 최후의 일격은 기본 전투 기록에서 이번 턴 모든 플레이어의 공격 사용 횟수를 세어 비용을 낮춘다. 투사의 형상은 다음 턴부터 에너지 1·2·3…을 주고 자신의 실제 재셔플 후 1부터 다시 시작한다. 다른 플레이어의 재셔플로 초기화되지 않는다.

- 후속 수치 조정: 시작 HP 70→80. 분노의 타격 8(11)→9(12), 시아르쿤 14(18)→16(20), 육중한 타격 18(22)→18(23), 광란의 타격 7(10)→8(11), 집념의 타격 10(14)→14(18), 망혼의 타격 10(14)→12(16), 필사의 타격 28(38)→30(40). 기존 진행 중인 저장 파일의 체력은 소급 변경하지 않는다.
- **새 카드 18종:** 분쇄의 타격, 투쟁, 재정비, 극복, 마검의 숙명, 피의 속삭임, 검의 마성, 해방, 모여드는 혼, 망념의 그릇, 희귀 이성의 의지, 전사의 신념, 저력, 무쌍의 검, 혼의 군세, 군도의 무예, 바다의 전사, 침식의 저주.
- **집념의 타격:** 비용 1, 피해 10(14), 불실·소멸 제거. 손에 저주로 취급되는 카드가 있어야 수동 사용할 수 있다. 윌드로 저주가 된 집념의 타격 자신도 손에 있으면 조건에 포함된다. 자동 사용의 기본 규칙은 원본 게임 명령을 따른다.
- **눈속임:** 피해 뒤 1드로우 추가. 재정비도 전투 중 재셔플마다 비용이 1 증가한다.
- **희귀도·비용:** 복수의 원혼은 희귀로 이동하고 불실을 얻는다. 혼의 열기는 희귀·비용 1(0)이다.
- **이름:** 기존 고급 이성의 의지는 찰나의 평정, 투지는 끝없는 투지로 변경한다. 일반 극기는 유지하고, 이름이 중복된 희귀 파워는 사용자 확정에 따라 **저력**으로 표시한다. 고급 극복은 그대로다. 기존 모델 ID는 유지하며 희귀 이성의 의지는 별도 모델이다.
- **표시·파일명 후속 정리:** 에너지 획득 카드와 관련 파워는 한·영 모두 전용 에너지 아이콘을 사용한다. 캐릭터 정의 파일은 `Althea.cs`, 문장 프리셋은 `althea.json`, 설계 문서는 `althea-design.md`로 옮기고 기존 저장 ID는 유지했다.
- **날랜 걸음 셔플 추적 수정:** 즉시 드로우 전에 다음 턴 드로우 파워를 부여한다. 즉시 드로우 중 재셔플이 일어나도 해당 파워가 셔플을 감지해 다음 턴 보너스를 취소한다.
- **피의 속삭임:** 뽑을 더미에서 저주 취급 카드만 찾아 실제 드로우한다. 손이 가득 차거나 해당 더미에 저주가 없으면 멈춘다. 버린 더미를 재셔플해 추가 탐색하지 않는다. 저주 수확 등 일반 드로우 반응도 발생한다.
- **희귀 이성의 의지:** 손에서 1장을 재편하고, 그 카드뿐 아니라 **이번 턴 재편된 모든 카드**가 해당 턴 사용할 때 2회 발동한다. 먼저 재편한 카드도 포함한다. 턴 종료 시 추가 발동 효과가 사라진다.
- **군도의 무예:** 공격 카드가 실제 지불한 에너지를 전투 동안 누적해 3마다 1을 돌려준다. 무료 자동 사용은 0, 광란은 실제 소비량만 센다. 이월분은 다음 턴에도 유지한다.
- **전사의 신념:** 힘을 즉시 얻고 자기 자신을 뽑을 더미에 무작위로 넣는다. 해당 힘은 다음 실제 덱 셔플 때 제거한다. 카드를 더미에 삽입하는 것 자체는 셔플 만료로 취급하지 않는다.
- **저력:** 최신 시트에 따라 해로운 파워를 적용받는 사건마다 카드 2장을 뽑는다. 기본/강화 모두 2드로우이며 비용만 1→0이다. 한 번에 부여한 중첩 수만큼 반복하지 않고, 디버프 감소·자연 만료에는 발동하지 않는다. 적이 부여한 음수 힘 등도 포함하며 기본 드로우 금지·손 제한을 따른다.
- **무쌍의 검:** 기존 약화 배율을 반전한다. 일반 약화의 0.75배는 1.25배가 되며 기존 약화 파워의 지속시간과 다른 약화 배율 보정은 재사용한다.
- **침식의 저주:** 사망을 한 번 방지해 최대 HP의 30%를 회복하고 힘 6(10)을 얻은 뒤 효과를 제거한다. 기본부터 선천성이다. 먼지쌓인 책은 기존 획득 방식대로 강화본을 준다.
- **고대 경로:** 고대의 이빨(`ArchaicTooth`)에 분노의 타격→최강의 타격 변환을 등록한다. 기본 게임처럼 덱에서 해당 카드 한 장을 교체하고 강화·인챈트를 계승한다. 최강의 타격은 먼지쌓인 책 후보에서 제외되어 침식의 저주가 그 경로의 전용 카드가 된다. 오로바스의 손은 윌드→피의 광란 교체만 맡는다.

## 공통 규칙

| 규칙 | 구현한 동작 |
|---|---|
| 광란 | 사용 카드가 손에서 빠지기 직전의 양옆을 확보한다. 좌→우로 예약하고 후속 연쇄는 FIFO로 이어 붙인다. 같은 카드의 중복 예약을 막고, 사용 전에 손 이탈·사용 불가·대상 생존을 다시 확인한다. |
| 광란 비용·대상 | 정상 비용과 남은 에너지 중 작은 값을 소비한다. 0에서도 사용하며 음수가 되지 않는다. 원래 적이 살아 있으면 이어받고, 아니면 전투 RNG로 살아 있는 적을 선택한다. |
| 윌드·피의 광란 | 타격 태그 또는 모든 공격에 저주 취급과 전투 중 보존을 제공한다. 원래 공격 타입·타격 태그는 유지한다. |
| 기본 게임의 저주 호환 | 기본 카드·파워·유물의 직접적인 Curse 타입 비교에 추가 저주 판정을 연결했다. 다른 모드의 독자적인 타입 검사까지 포괄하는 호환성을 보장하지 않는다. |
| 재편 | 원래 타입에 따라 시아르쿤·를레우르흐·모르피엘라·순수한 의지로 전투 중 변형한다. 강화 여부와 결과 카드에 적용 가능한 인챈트를 계승하고 덱 원본은 유지한다. |
| 불실 | 소멸 또는 변형 시 덱 원본의 종류·강화·인챈트만 복사한다. 전투 중 강화·비용·누적 수치는 제외한다. 덱 원본이 없는 생성 카드는 같은 종류의 강화/미강화 여부만 보존한다. |
| 격전 | 카드 효과 실행 직전에 자신 또는 살아 있는 적 하나라도 HP가 최대의 절반 이하인지 확인한다. 그 카드의 피해로 뒤늦게 충족한 조건은 적용하지 않는다. |
| 해로운 효과 | 약화·취약·손상은 출처와 무관하게 포함하며, 그 밖에는 적이 부여한 파워만 포함한다. 적이 부여한 음수 힘도 추적한다. 개수는 현재 남아 있는 서로 다른 효과 종류 수다. |
| 망령 | 비용 1·저주·휘발성·소멸이다. 사용 효과는 따로 없고 소멸할 때 1장을 뽑는다. |
| 피해 참조 | 쳐내기·칼집 휘두르기·라웨나이드는 버리기 직전의 적 미지정 표시 피해를 고정하고 다단 피해를 합산하며 X는 0으로 센다. 공격을 가짜로 실행하지 않는다. |

## 초기 구현에서 채택한 세부 동작

이전 검토에서 열어 두었던 항목은 다음 기준으로 구현했다. 추가 밸런스 조정 때 변경할 수 있다.

- 노도의 타격의 공격 장수에는 자신을 포함한다. 반복 사용도 실제 플레이 훅의 횟수로 센다.
- 상어의 자세는 한 턴에서 공격 3장마다 반복 발동한다. 비공격을 사용하거나 새 턴이 시작하면 연속 횟수가 초기화된다.
- 복수의 원혼은 현재 소멸 더미의 저주 취급 카드 N장에 대해 N+1회 공격하고, 매 타격마다 무작위 적을 다시 정한다.
- 사자의 도약 중첩은 2배씩 곱한다. 범고래의 급습 중첩은 얻는 방어도 배수를 더한다. 다음 공격 카드 전체의 다단·전체 공격에 적용한 뒤 기존 중첩만 소모한다. 부여한 카드 자신의 공격에는 새 효과를 적용하지 않는다.
- 영혼의 조언은 손의 다른 카드를 무작위로 소멸한다. 부족하면 있는 카드만 소멸하고 드로우를 진행한다.
- 눈속임의 비용 증가는 첫 배치 이후 버린 더미를 재셔플할 때 적용하며 전투 한정이다. 투사의 완갑도 초기 배치를 제외한 첫 재셔플 이후 비활성화한다.
- 위업의 길은 턴마다 첫 카드에 한 번 적용한다. 사용을 끝낸 뒤 재편 토큰을 뽑을 더미 맨 위에 놓되, 원래 결과가 소멸이면 토큰도 소멸한다. 불실은 원본에서 한 번만 발동한다.
- 최강의 타격은 각 사용에서 적을 죽이면 현재 카드의 복사본을 영구 덱에 한 장 추가한다. 오로바스의 손은 윌드를 피의 광란으로 교체하고, 고대의 이빨은 분노의 타격 한 장을 최강의 타격으로 변형한다. 강화·적용 가능한 인챈트를 계승한다.
- 크레킨 막 두브는 취약의 받는 피해 배율을 1.2, 손상의 방어도 배율을 0.8로 설정한다. 지속 턴 수는 바꾸지 않는다.
- 무장 해제는 기존 `MonarchsGazeStrengthDownPower`의 힘 감소·대상 턴 종료 후 복구를 따른다. 공격할 때 힘을 낮추는 부여 효과 자체는 이번 아군 턴 종료 시 사라진다.

## 구현 위치와 유지보수

`Sts2WDCode/Characters/CharacterTwo/`가 Althea 규칙을 소유한다. `Cards/AltheaCards.cs`는 안정적인 카드 모델 ID와 수치, `AltheaCard.cs`는 공통 표시·강화, `AltheaCardEffects.cs`는 카드 효과를 담당한다. `AltheaRules.cs`의 전투별 상태와 실행 경계에서 광란·재편·불실을 연결하며, `AltheaCombatHooks.cs`가 공통 전투 이벤트를 받는다. `Powers/AltheaPower.cs`는 공통 아이콘·파워 기본값만 정의하고, 각 `Althea*Power.cs`가 해당 효과의 훅과 상태를 소유한다. `Relics/AltheaRelics.cs`는 전용 유물, `AltheaCompatibility.cs`는 기본 게임의 저주 검사·변형·오로바스·디버프 배율에 연결한다.

쉼없는 광기는 `AfterCombatEnd`에서 손·뽑을 더미·버린 더미의 저주를 집계해 회복한다. 기본 게임의 `CombatManager.EndCombatInternal`은 이 훅 다음에 `Player.AfterCombatEnd`로 파워를 제거하고 전투 더미를 비운 뒤 `AfterCombatVictory`를 호출하므로, 회복을 승리 훅에 두면 실행되지 않는다. 소멸 더미는 제외하며 유물로 저주 취급되는 타격 카드도 포함한다.

해로운 효과의 공통 판정은 `AltheaRules.IsHarmful`이 소유한다. 취약·약화·손상은 출처와 무관하게 포함하고, 그 밖에는 적이 부여한 효과만 포함한다. `PowerType.Debuff`만으로는 포함하지 않는다. 현재 효과 종류 집계는 기록된 적 출처를 사용하고, 저력의 드로우는 이번 부여의 출처를 사용한다. 따라서 적이 부여했던 효과를 자신이 증감해도 저력이 추가 발동하지 않으며, Debuff 감소·제거도 새 부여로 세지 않는다.

시트 행 번호를 저장 ID로 사용하지 않는다. 카드 타입을 전역으로 Curse로 바꾸거나 레아르타의 전용 강화·유산·수호를 Althea 규칙에 섞지 않는다. 기본 힘·민첩·약화·취약·손상·다음 공격 무료는 기존 효과를 사용한다.

기존 정식 테스트는 추가·수정하지 않았다. 별도 임시 Godot 실행에서 실제 `CardModel.OnPlayWrapper`, 공격·파워·변형 명령으로 다음을 관찰했다.
