## Verification Scope and Reading Guide

The 2026-10-19 combat/merchant rig revision includes occluded joint surfaces, front/back coat pieces, an attack grip, hurt/death leg motion and landing in-between cels. Runtime PNGs and the source mappings in parts.json/meshes.json are build inputs; [animation/README.md](../../animation/README.md) owns files and reproduction. Seven clips totaling 396 rendered frames and publish completed. Observations from the new PCK covered two scenes, ten playback names, added textures, action return, death hold and revive reset. Game installation and actual gameplay were not checked; the twelve rest/select originals retained their starting hashes.

The combat expression textures `Sts2WD/animations/realta/combat/parts/head-closed.png`, `head-hurt.png`, and `head-attack.png` were regenerated separately and registered by scale/translation against unchanged hair, hat and ear regions. Each remains 188×126 RGBA at source offset `(140,99)`, with alpha identical to the untouched `head.png`. One connected facial-skin mask preserves hair/hat outside the face and the original dark jaw junction. Matching 384×576 source layers place each complete runtime rectangle at `(140,99)` for future export consistency; these intermediate layers are optional local working material. Three visual review passes included 8× face views on grey/dark and head-over-torso at scale 0.625. This PNG-only update did not run Godot import, packaging, installation or game verification; existing packaged assets may therefore predate these textures.

- Historical rollback verification checked that the restored `combat.png` exactly matched the former base-derived `standing.png` and that all three scenes referenced `combat.png` before animation integration. The extra standing PNG and its import descriptor are removed. See [standing rollback](assets.md#standing-and-combat-split) for packaging/resource-loading observations. These are not formal tests or product acceptance; actual gameplay and other aspect ratios remain unverified.
- The approved `base.png` was unchanged during downstream production. [delivery conversion](../shared/conversion.md) describes delivery conversion.
- An approximate selection-UI overlay obscured part of the working hand behind the left description panel. The face and blade remained visible, and the selected composition was applied unchanged. This was neither a game capture nor a formal test; text and action readability still need an actual gameplay check.
