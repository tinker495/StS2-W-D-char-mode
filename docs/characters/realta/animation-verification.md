# 레아르타 애니메이션 확인 범위

<a id="combat-expressions"></a>

## 전투와 상점의 표정

머리 그림이 코·얼굴 윤곽·머리카락을 담당하고, `eye_r`(캐릭터 오른눈·화면 왼쪽)·`eye_l`(캐릭터 왼눈·화면 오른쪽)이 각 표정의 눈썹·눈꺼풀을, `mouth`가 입을 담당한다. 여섯 상태의 좌표 등록과 3텍셀 아틀라스 추출 계약은 [제작 소스](animation-sources.md#inputs-and-ownership)를 따른다.

| 상태 | 확인할 동작과 얼굴 |
|---|---|
| `neutral` | 전투 대기(`idle_loop`)의 기본 눈·입 상태. 눈썹 끝이 앞머리 방향을 따른다. |
| `closed` | 눈을 감은 상태. 전투 대기의 Track 1 `blink_loop`(`3.60초`)는 양 눈만 바꾸고 기본 입을 유지하며 액션 전환 시 즉시 해제된다. |
| `hurt` | 피격(`hurt`) 때 좁힌 눈과 찡그린 눈썹, 달라진 입. |
| `attack` | 공격(`attack`), 방어(`guard`), 시전(`cast`) 중 힘을 준 눈·눈썹과 입. |
| `ponder` | 상점(`relaxed_loop`)에서 턱을 괴고 흥얼거리는 얼굴. |
| `fallen` | 쓰러진 뒤(`die`) 양 눈이 감기고 눈썹이 안쪽으로 당겨진다. 조금 벌어진 입으로 숨을 내쉰다. |

## 동작을 확인하는 위치

- **공격(`attack`)과 방어(`guard`).** 공격 준비와 `0.54초` 찌르기 정점에서는 두 주먹과 자루, 양쪽 완갑의 끝, 견갑과 팔꿈치, 관통 기류·섬광을 함께 본다. 방어(`0.18초` `guard_brace`)에서는 대각선으로 세운 자루와 왼손(`hand_l-casting`) 앞 비전 방어막(`sigil_inner`·`sigil_core`)이 몸통 앞 레이어에서 자연스럽게 겹쳤다가 복귀하는지 확인한다.
- **하체와 치마.** 앞발이 내딛거나 무릎을 낮출 때 치마 안감(`coat_back`)과 앞자락(`coat_r`·`coat_l`)의 옆선이 접힘(mesh fold) 없이 함께 움직이고 무릎이 앞트임 안쪽에 보여야 한다.
- **시전(`cast`)과 쓰러짐(`die`).** 시전(`0.25초`) 때는 왼팔이 몸통 뒤에서 뻗어 손끝에서 세 겹 마법진이 나오는지 확인한다. 쓰러질 때는 `0.12초`에 풀리는 오른손과 먼저 떨어지는 창, `1.66초`까지 바닥에 닿아 정지하는 모자·뺨·손바닥(`hand_r-ground`)을 확인한다.
- **좌우 반전(`FlipX`)과 선택 화면.** 적 조우·거울 연출 등에서 `FlipX`(`scale_x = -1`)가 적용되어도 본 좌표나 제약이 깨지지 않고 대칭 반전되는지, 캐릭터 선택 화면(`char_select_bg_realta.tscn`)이 `16:9`와 `3:2` 화면비 모두에서 배경과 오버레이 어긋남 없이 단일 `"animation"` 루프를 재생하는지 함께 확인한다. [모션과 타이밍](animation-sources.md#clips-and-dispatch)

제작 소스에서 재생하는 동작과 PCK에서 읽은 장면은 각각 렌더해 확인한다. 실제 게임 설치본에서 확인한 범위는 [재현 절차](animation/reproduction.md), [장면 변환 API](animation-api.md), [공통 배포 기록](/docs/deployment-status.md)을 따른다.
