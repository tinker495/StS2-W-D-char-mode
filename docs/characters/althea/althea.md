# 알테아 (Althea) 설계 명세

알테아(Althea)의 캐릭터 규칙, 핵심 키워드, 개별 카드·유물 확정 동작 및 원작 엔진 제약을 정리한 문서다. 리소스 매핑은 [에셋 상태](althea-assets.md), 로컬 설치 범위는 [배포 기록](/docs/deployment-status.md)을 따른다.

## 기본 정보

- **표시 이름:** 한국어 **알테아**, 영문 **Althea**
- **시작 체력:** 80
- **시작 덱 (10장):** 분노의 타격 1장, 기본 타격 5장, 기본 방어 4장
- **시작 유물:** 윌드
- **참조 카드 미리보기:** 망령·의심·수치를 참조하는 카드와 재편을 설명하는 카드·파워에 참조 카드 미리보기를 표시한다. 대상 미정 재편은 타입별 결과 카드 4종(시아르쿤·를레우르흐·모르피엘라·순수한 의지)을 함께 표시하고, 전사의 타격처럼 대상이 자기 자신으로 확정된 카드는 확정 결과(시아르쿤 / 시아르쿤+)만 표시한다. 망령 미리보기는 생성 카드의 강화 여부와 무관하게 미강화 카드로 표시한다. 공통 표시 기준은 [공통 표시 규칙](/AGENTS.md#card-reference-previews)을 따른다.

## 기본 유물

- **윌드:** 모든 타격 카드를 저주로도 취급하고 보존한다.
- **피의 광란 (강화 시작 유물):** 모든 공격 카드를 저주로도 취급하고 보존한다. 오로바스의 손으로 윌드를 교체할 때 얻는다.
- '타격 카드'는 기본 타격만이 아니라 이름에 '타격'이 붙은 모든 카드를 뜻한다.
- 윌드·피의 광란의 영향을 받은 카드는 원래 공격 카드의 성질·타격 태그·사용 가능 여부를 유지하면서 저주 관련 효과에도 포함된다. 공격 시너지와 저주 시너지를 모두 받는다.
- 재편으로 변형할 때는 원래 카드 타입을 기준으로 분류한다. 유물로 저주 취급을 받는 공격 카드도 공격용 토큰(시아르쿤)으로 변형한다.
- **기본 게임 저주 호환 범위:** 기본 게임의 카드·파워·유물이 수행하는 직접적인 `Curse` 타입 비교에 추가 저주 판정을 연결한다. 다른 모드의 독자적인 타입 검사까지 포괄하는 호환성은 보장하지 않는다.

## 주요 컨셉

| 테마 | 규칙 |
|---|---|
| 자가 상태이상 | 스스로에게 디버프를 거는 대신 강력한 효과를 얻거나, 자신에게 걸린 디버프를 활용한다. 상태이상 카드 생성 중심의 테마는 아니다. |
| 공격 카드 시너지 | Ironclad의 공격 카드 관련 시너지를 일부 공유하고, 캐릭터 고유의 시너지를 추가한다. |
| 광란 | 손에 있을 때 바로 왼쪽 또는 오른쪽에 있는 카드를 사용하면 그 뒤에 자동으로 사용된다. 카드 유형은 조건으로 삼지 않는다. 에너지가 부족하거나 없어도 사용되며, 에너지는 0 미만으로 내려가지 않는다. |
| 저주 | 전투 중 일시적으로 저주 카드를 생성하거나 저주와 연계되는 효과를 활용한다. 덱이나 손에 생성하는 방해 카드는 주로 저주 카드로 설계하며, 자가 디버프와는 구분한다. |
| 전략 | 카드 수에 따른 이점과 원하는 카드 탐색을 다루는 테마다. 어떤 카드의 수를 참조하는지는 각 카드에 명시하며, 공통 키워드나 하나의 계산 규칙으로 통일하지 않는다. |

## 서브 컨셉

| 테마 | 규칙 |
|---|---|
| 재편 | 기본적으로 손의 카드 하나를 선택해 해당 전투 동안 원래 타입에 맞는 토큰 카드(공격→시아르쿤, 스킬→를레우르흐, 파워→모르피엘라, 그 외→순수한 의지)로 변형한다. 강화 상태와 결과 토큰에 적용 가능한 인챈트를 계승하며 영구 덱은 유지한다. 다른 더미를 대상으로 하는 카드는 개별 카드에 명시한다. |
| 소멸 | 카드를 소멸시켜 저주 등의 페널티를 회피하고 덱을 정제하며 순환을 보조한다. |
| 격전 | 카드 효과 실행 직전에 자신 또는 살아 있는 적 하나라도 최대 HP의 절반 이하이면 추가 효과를 얻는다. 해당 카드의 피해로 뒤늦게 조건을 충족해도 발동하지 않는다. |
| 불실 | 소멸하거나 변화되면 변화·소멸 전 카드의 덱 원본을 기준으로 복사본을 손에 추가한다. 원본의 강화·인챈트만 반영하며, 전투 중 비용 변경이나 누적 수치 등은 복사하지 않는다. 덱 원본 없는 전투 생성 카드는 강화/미강화 여부만 반영한다. |
| 망령 | 1코스트 저주 토큰 카드다. 휘발성·소멸을 가지며, 소멸하면 카드 1장을 뽑는다. 별도 사용 효과는 없으며 사용 시 소멸하면서 1장을 뽑고, 휘발성으로 소멸해도 같은 드로우 효과가 발동한다. 소멸 드로우는 카드 자신이 소유해 다른 캐릭터가 받아도 작동한다. |

## 광란의 공통 규칙

- 자동 사용도 정상 비용을 지불하되, 비용보다 에너지가 적으면 남은 에너지만 소비한다. 에너지 0에서도 자동 사용되며, 에너지는 음수가 되지 않는다.
- 광란으로 자동 사용된 카드도 인접한 다른 광란 카드를 발동시킨다.
- 인접 판정은 사용한 카드가 손을 떠나기 직전의 배치를 기준으로 한다. 카드가 빠진 뒤 새로 이웃이 된 카드는 그 사용에 반응하지 않는다.
- 한 번의 카드 사용으로 양옆의 광란이 모두 발동하면 왼쪽 카드부터 오른쪽 카드 순서로 처리한다.
- 먼저 발동한 카드부터 처리하고 후속 연쇄는 뒤에 이어 붙인다(FIFO). 양옆 A·B가 발동하고 A가 C를 발동시키면 A → B → C 순서다.
- 자동 공격은 발동을 유발한 카드의 적 대상을 이어받는다. 유발 카드에 적 대상이 없거나 그 적이 이미 죽었다면 전투 RNG로 살아 있는 무작위 적을 대상으로 한다.
- 이미 자동 사용을 기다리는 카드는 다른 카드에 반응해도 중복으로 예약하지 않는다. 사용 후 다시 손으로 돌아온 카드의 재발동을 금지하는 규칙은 아니다.
- 사용 대기 중인 카드가 손을 떠났거나 소멸·재편됐거나, 에너지 이외의 사용 조건 때문에 사용할 수 없게 되면 그 카드의 예약만 취소한다. 나머지 예약은 계속 처리한다. 에너지 부족은 자동 사용을 막지 않는다.

## 불실의 복사 기준

- 변화 후의 토큰이 아니라 변화 전 카드의 덱 원본을 기준으로 한다. 소멸도 해당 카드의 덱 원본을 기준으로 한다.
- 원본에 있는 강화·인챈트를 반영하고, 원본에 없는 전투 중 일시적 강화·인챈트나 비용 변경·누적 수치는 가져오지 않는다.
- 덱 원본이 없는 전투 생성 카드는 같은 카드의 기본 상태로 복귀하되, 발동 전 강화 여부만 반영한다. 강화 횟수·인챈트·일시 비용·누적 수치를 그대로 복제하지 않는다.

## 해로운 효과 판정

- `AltheaRules.IsHarmful`이 공통 판정을 소유한다.
- 취약·약화·손상은 출처와 무관하게 포함하며, 그 밖에는 적이 캐릭터에게 부여한 효과(적이 부여한 음수 힘 포함)만 포함한다. `PowerType.Debuff`라는 이유만으로 포함하지 않는다.
- 현재 효과 개수는 남아 있는 서로 다른 효과 종류 수다(예: 약화 3·취약 2는 2종). 겐 모르피 클라드 등 개수 참조 카드에 이 기준을 적용한다.
- 결의 등 부여 반응 파워는 이번 부여의 출처를 확인하므로, 적이 부여했던 효과를 자신이 증감하거나 디버프가 감소·제거되는 사건은 새 부여로 세지 않는다.

## 개별 카드·유물 확정 규칙

- **피해 참조 (쳐내기·칼집 휘두르기·라웨나이드):** 버리기 직전의 적 미지정 현재 표시 피해를 참조한다. 다단 공격은 합산하고, X코스트 공격은 X=0으로 계산한다. 실제 공격을 실행하거나 적에게 피해를 주어 값을 측정하지 않는다.
- **노도의 타격:** 이번 턴 공격 카드 장수 집계에 자기 자신을 포함한다. 반복 사용도 실제 플레이 훅 횟수로 센다.
- **상어의 자세:** 한 턴에서 공격 3장마다 반복 발동한다. 비공격을 사용하거나 새 턴이 시작하면 연속 횟수가 초기화된다.
- **사자의 도약 / 범고래의 급습:** 사자의 도약 중첩은 피해 배율을 2배씩 곱하고, 범고래의 급습 중첩은 얻는 방어도 배수를 더한다. 다음 공격 카드 전체의 다단·전체 공격에 적용한 뒤 기존 중첩만 소모하며, 부여한 카드 자신의 공격에는 새 효과를 적용하지 않는다.
- **복수의 원혼:** 원래 저주뿐 아니라 윌드·피의 광란 등으로 저주 취급받는 소멸 더미의 카드도 센다. 저주가 N장이면 기본 1회에 N회를 추가해 총 N+1회 공격하며, 매 타격마다 무작위 적을 다시 정한다.
- **마검의 숙명:** 불실·휘발성을 가지며 사용만으로 소멸하지 않는다. 반복 강화가 가능하며, 소멸할 때마다 영구 덱 원본은 변경하지 않고 전투 중 강화가 누적된 복사본으로 돌아온다. 이 카드의 복귀에는 일반 불실의 강화 초기화보다 개별 효과가 우선한다.
- **이성의 의지:** 이번 턴 재편된 카드(이미 재편한 카드와 파워 토큰 포함)를 사용하면 2회 발동한 뒤 소멸한다. 턴 종료 시 효과가 사라진다.
- **악전고투:** 다음 턴의 기본 5장 드로우만 생략하고 유물·카드의 추가 드로우는 유지한다. 중복 사용해도 생략을 중첩하지 않는다.
- **저력:** 해로운 효과가 완전히 제거될 때마다 제거된 효과 종류마다 다음 턴 에너지 1을 예약한다. 사용 직후 자신에게서 취약과 손상을 제거하며, 그 자체 제거도 각각 발동한다. 일부 수치 감소만으로는 발동하지 않는다.
- **빛바랜 문장:** 저주(유물로 저주 취급되는 공격 카드 포함) 소멸마다 다음 턴 에너지를 예약한다. 영구 덱에 추가할 때 기본 게임의 어리석음(`Folly`) 1장을 추가한다.
- **눈속임 / 재정비 / 투사의 완갑 / 투사의 형상 / 전사의 신념:** 눈속임·재정비의 비용 증가와 투사의 완갑 비활성화는 전투 준비의 초기 배치를 제외한 버린 더미의 실제 재셔플에만 반응한다. 투사의 형상 역시 자신의 실제 재셔플 후 초기화되며 다른 플레이어의 재셔플로 초기화되지 않는다. 전사의 신념은 자신을 뽑을 더미에 섞어 넣는 행위를 셔플 만료로 취급하지 않고, 다음 실제 덱 셔플 때 부여한 힘·민첩을 회수한다.
- **위업의 길:** 턴마다 첫 카드에 한 번 적용한다. 사용을 끝낸 뒤 재편 토큰을 뽑을 더미 맨 위에 놓되, 원래 결과가 소멸이면 토큰도 소멸한다. 불실은 원본에서 한 번만 발동한다.
- **망념의 그릇:** 생성한 망령을 `CardPileCmd.AddGeneratedCardToCombat`에 `CardPilePosition.Random`으로 전달해 현재 뽑을 더미 안에서 삽입 위치를 정한다. 뽑을 더미가 비어 있을 때 추가하면 다음 드로우는 해당 망령부터 뽑고, 뽑을 더미가 다시 비어야 버린 더미를 섞는다(`NCardPileScreen.OnPileContentsChanged`의 희귀도·카드 ID 정렬은 뽑을 더미 화면의 표시 순서일 뿐이다).
- **피의 속삭임:** 뽑을 더미에서 저주 취급 카드만 찾아 손이 찰 때까지 실제 드로우한다. 버린 더미를 재셔플해 추가 탐색하지 않으며, 저주 수확 등 일반 드로우 반응이 발생한다.
- **바다 가르기:** 비용은 현재 자신의 버린 더미·소멸 더미의 저주 취급 카드 장수로 계산한다. 누적 버리기·소멸 횟수가 아니며, 저주가 해당 더미에서 빠져나오면 비용이 다시 오른다.
- **저주 장악:** 멀티 전용이며, 다른 모든 플레이어의 손·뽑을 더미·버린 더미의 저주 취급 카드만 가져온다. 소멸 더미와 영구 덱은 건드리지 않는다. 전투 카드 인스턴스와 강화·비용·인챈트·덱 원본 연결을 유지한 채 소유자와 더미만 옮기며, 이동 후 저주 판정은 새 소유자의 유물을 따른다. 영혼 장막·최후의 일격도 기본 게임의 멀티 전용 제약을 사용한다.
- **군도의 무예:** 이전 턴을 포함해 이번 전투에서 재편된 카드나 공격 카드가 실제 소비한 에너지를 누적한다. 재편된 공격을 중복 집계하지 않으며, 무료 자동 사용은 0·광란은 실제 소비량만 센다.
- **쉼없는 광기:** `AfterCombatEnd`에서 손·뽑을 더미·버린 더미의 저주(유물로 저주 취급되는 카드 포함, 소멸 더미 제외)를 집계해 회복한다. 원작 `CombatManager.EndCombatInternal`은 `AfterCombatEnd` 이후 `Player.AfterCombatEnd`로 파워를 제거하고 전투 더미를 비운 뒤 `AfterCombatVictory`를 호출하므로, 승리 훅에서는 실행될 수 없다.
- **무장 해제:** 원작 `MonarchsGazeStrengthDownPower`의 힘 감소·대상 턴 종료 후 복구 동작을 재사용한다. 공격 시 힘을 낮추는 부여 효과 자체는 이번 아군 턴 종료 시 사라진다.
- **크레킨 막 두브:** 취약의 받는 피해 배율을 1.2, 손상의 방어도 배율을 0.8로 설정한다. 지속 턴 수는 변경하지 않는다.
- **무쌍의 검:** 약화의 피해 배율을 반전(예: 0.75 → 1.25)하며, 기존 약화 파워의 지속시간과 다른 약화 배율 보정을 재사용한다.
- **고대 카드 경로 (최강의 타격 / 침식의 저주):** 고대의 이빨(`ArchaicTooth`)은 분노의 타격 1장을 최강의 타격으로 교체하고 강화·적용 가능한 인챈트를 계승한다. 최강의 타격은 먼지쌓인 책 후보에서 제외되어 침식의 저주가 먼지쌓인 책 전용 카드가 된다. 최강의 타격은 치명타 시 현재 카드의 복사본을 영구 덱에 추가한다.
- **사선돌파 / 영혼의 조언:** 사선돌파는 격전 시 뽑을 더미에서 카드 1장을 선택해 손으로 가져온다. 영혼의 조언은 손의 다른 카드를 무작위로 소멸시키며 부족하면 있는 만큼만 소멸한 뒤 드로우를 진행한다.

## 식별자와 저장 호환성

- 캐릭터 모델은 `Althea`(ID `STS2WD-ALTHEA`), 풀은 `AltheaCardPool`·`AltheaRelicPool`·`AltheaPotionPool`(ID `STS2WD-ALTHEA_CARD_POOL` 등)이다. 코드 경로는 `Sts2WDCode/Characters/Althea/`, 에셋 경로는 `Sts2WD/images/charui/althea/`·`Sts2WD/images/cards/althea/`·`Sts2WD/materials/althea/`, 문장 프리셋은 `althea.json`이다.
- 이전 자리표시 ID(`STS2WD-CHARACTER_TWO` / `CharacterTwo`)로 저장된 진행 중인 런과 기록은 새 ID로 자동 마이그레이션하지 않는다. 기존 진행 중인 저장 파일의 체력도 소급 변경하지 않는다.
- 시트 행 번호를 저장 ID로 사용하지 않는다. 카드 타입을 전역으로 `Curse`로 바꾸거나 다른 캐릭터(레아르타 등)의 전용 규칙을 알테아 규칙에 섞지 않는다.

## 원작 엔진 제약 (Self-Reform)

[`AltheaReformLifecycle`](/Sts2WDCode/Characters/Althea/AltheaReformLifecycle.cs)는 지연 재편, 턴당 첫 사용 카운터, 턴·전투별 재편 이력을 `PlayerCombatState` 기준 `ConditionalWeakTable`로 관리해 영구 덱을 변형하지 않으며, `PlayBoundary.Finish`에서 원 사용 태스크 완료 직후·광란 처리 직전에 지연 재편을 마무리한다.

자기 자신을 재편하는 카드(예: 전사의 타격 → 시아르쿤)에서 원본 카드의 화면 잔상이 남는 문제는 설치본 `sts2.dll` 제품 버전 `0.1.0+59260271157f76a2896f0eab5bc6ea1245d8b314` (Steam build `23811903`)의 모델·노드 분리 수명 주기 때문이다.

- `CardCmd.Transform`은 원본 카드를 Play 더미에서 제거하고 `RemoveFromState`를 호출한다. 손 더미 변형은 `NCardTransformShineVfx`로 원본 노드를 갱신하지만, Play 등 다른 더미에서는 원본 `NCard` 노드를 정리하지 않는다.
- `CardModel.OnPlayWrapper`는 원본 카드가 여전히 Play 더미에 속할 때만 결과 더미 이동과 시각 정리를 실행하므로, Self-Reform으로 이미 Play 더미에서 빠진 카드의 표시 정리를 건너뛴다.
- `CardPileCmd.RemoveFromCombat`은 카드가 전투 더미에 속해야 호출할 수 있어 Transform 이후에는 사용할 수 없고, 먼저 호출하면 Transform이 요구하는 원본 더미 전제를 깨뜨린다.
- 따라서 `AltheaReformLifecycle.Reform`은 원본이 Play 더미에 속한 경우에만 `CardCmd.Transform` 전에 `NCard.FindOnTable(source)`로 원본 노드를 확보하고, Transform 완료 후 해당 노드가 여전히 같은 원본을 표시하면 `GodotTreeExtensions.QueueFreeSafely()`로 씬 트리에서 분리해 `NodePool`로 반환한다(`NCard.OnFreedToPool`이 모델 구독과 재생 트윈을 해제한다).
