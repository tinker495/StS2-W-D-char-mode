# Althea Asset Status

This index routes applied files, the adopted draft base and native integration details. [Art direction](althea-art.md) owns appearance; [history](althea-history.md) owns past decisions. Draft character-design status and approval for specific runtime assets are separate.

| Work | Read first | Read when needed |
|---|---|---|
| Base selection, preservation or unresolved design scope | [Draft base status](base-assets.md) | [Appearance](base-appearance.md) |
| Combat, merchant or rest standing | [Standing delivery and scene connections](animation-standing.md#delivery-and-integration) | [Standing art](animation-standing.md#appearance) |
| Portrait, outline, map marker or file dimensions | [UI runtime inventory](ui-assets.md) | [UI art](ui-art.md) |
| Selection tile or background | [Selection delivery](selection-assets.md), [UI runtime inventory](ui-assets.md) | [Selection art](selection-art.md) |
| Card-cost and inline energy textures | [Energy delivery](ui-energy.md#delivery-and-integration) | [Energy art](ui-energy.md#appearance) |
| Card frame and cost layout | [Frame integration](cards-frames.md#delivery-and-integration) | [Frame art](cards-frames.md#appearance) |
| Card portraits, temporary palettes or Wraith source | [Portrait integration](cards-assets.md) | [Portrait art](cards-art.md) |
| Relic filenames, approval or conversion | [Relic deliveries](relics-assets.md) | [Relic art](relics-art.md) |

Package installation and shared verification for the 2026-10-24 card/relic/Aselige release belong to [deployment status](/docs/deployment-status.md). The later standing, UI and selection deliveries retain their separate application and installation observations in the linked topics. Historical installation records do not establish the current checkout's installed state.
