# Althea Asset Status

This index routes applied files, the adopted draft base and native integration details. [Art direction](althea-art.md) owns appearance; [history](althea-history.md) owns past decisions. Draft character-design status and approval for specific runtime assets are separate.

| Work | Read first | Read when needed |
|---|---|---|
| Base selection, preservation or unresolved design scope | [Draft base status](visuals/base/assets.md) | [Appearance](visuals/base/appearance.md) |
| Combat, merchant or rest standing | [Standing delivery and scene connections](visuals/animation/assets.md) | [Standing art](visuals/animation/art.md) |
| Portrait, outline, map marker or file dimensions | [UI runtime inventory](visuals/ui/assets.md) | [UI art](visuals/ui/art.md) |
| Selection tile or background | [Selection delivery](visuals/selection/assets.md), [UI runtime inventory](visuals/ui/assets.md) | [Selection art](visuals/selection/art.md) |
| Card-cost and inline energy textures | [Energy delivery](visuals/ui/energy-assets.md) | [Energy art](visuals/ui/energy-art.md) |
| Card frame and cost layout | [Frame integration](visuals/cards/frames.md) | [Frame art](visuals/cards/frame-art.md) |
| Card portraits, temporary palettes or Wraith source | [Portrait integration](visuals/cards/assets.md) | [Portrait art](visuals/cards/art.md) |
| Relic filenames, approval or conversion | [Relic deliveries](visuals/relics/assets.md) | [Relic art](visuals/relics/art.md) |

Package installation and shared verification for the 2026-10-24 card/relic/Aselige release belong to [deployment status](../../deployment-status.md). The later standing, UI and selection deliveries retain their separate application and installation observations in the linked topics. Historical installation records do not establish the current checkout's installed state.
