# 에레닐 아트 가이드

에레닐의 복장과 마법 표현은 [전신 원화와 참고 그림](base-art.md#외형)을 기준으로 삼는다. 캐릭터 설정은 [에레닐 설계](erenil.md), 게임에서 사용하는 리소스는 [에셋 현황](erenil-assets.md)에서 확인할 수 있다.

## Production Routing

Use the [standing master](base.png) for character identity and [ARTS.md](/ARTS.md) for rendering. The six template UI textures and the `#9b72cf` color in [Erenil.cs](/Sts2WDCode/Characters/Erenil/Erenil.cs) are runtime placeholders.
