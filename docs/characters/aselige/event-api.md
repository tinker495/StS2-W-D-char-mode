# Aselige Runtime Integration

Sts2WDCode/Ancients/Aselige/Aselige.cs derives from BaseLib 3.4.7 CustomAncientModel, entry STS2WD-ASELIGE, and explicitly supplies the scene, map and history icon paths. AseligeHooks replaces the first Act's generated Ancient for any party containing a mod character. Native-only parties and later Acts retain their generated Ancients. NAncientDialogueLine uses the history icon/outline for the speaker; NAncientNameBanner reads the complete title and empty epithet.

AseligeRelics owns the 14 concrete effects and save properties. The two granted cards are implemented as zero-cost Skills. AseligeDialogues selects the authored 13 conversations per visitor and first Act, without caching run-specific text on the canonical model. Korean and English runtime localization includes relics, cards, event descriptions, Blitz option/completion entries and all dialogue lines/continuation buttons.

Against `sts2.dll` `v0.113.1`, `Aselige.GenerateInitialOptions` mirrors native `Neow` precedence: when `BlitzRunModel` is active, it offers a single Blitz option calling static `BlitzRunModel.GiveNeowRewards` and chains any `ModifierModel.GenerateNeowOption` callbacks; when non-Blitz runs have `RunState.Modifiers.Count > 0`, it skips gift relics and runs only modifier Neow options (falling through to `AncientEventModel.StartPreFinished()` when none exist). Because `EventModel.OptionKey` omits BaseLib's `STS2WD-` prefix, Blitz keys resolve via `L10NLookup($"{Id.Entry}...")`, and Blitz/modifier paths finish via `SetEventFinished` directly rather than `Done()` so `AncientChoices` omits non-relic options. `AseligeLifeSource` disallows `GameMode.Blitz` via `IsAllowedInternal`, guards `AfterObtained()`, and wraps only standard-run generated map types (`StandardActMap`, `SpoilsActMap`, `GoldenPathActMap`) so `AseligeLifeMap` never erases `BlitzActMap` required by `RunManager.TryAdvanceToNextBlitzNode()`.

Because `NAncientEventLayout.InitializeVisuals()` parents background scenes under `NAncientBgContainer` (whose `OnWindowChange()` scales and offsets by aspect ratio, e.g. `0.89x` and `+40Y` at 16:9), `Aselige.ConfigureBackgroundScene` binds a `static` inverse-transform helper that projects viewport corners through `NAncientBgContainer.GetTransform().AffineInverse()` on `TreeEntered` and deferred `Window` `SizeChanged` (disconnecting on `TreeExited` without capturing model/run state).

In native run creation, `RunState.CreateForNewRun` clones acts via `ToMutable` (`ActModel.DeepCloneFields` allocates a new `RoomSet`) and `AssertMutable` guards `run.Acts[0]`, isolating the replaced first-Act Ancient to that mutable run state rather than mutating canonical models. Initial deck randomization uses `CardPile.RandomizeOrderInternal`, which does not emit `AfterShuffle`, so shuffle-triggered gift relics only fire on actual mid-combat reshuffles.
