# 레아르타 (Realta) 설계 합의

사용자와의 설계 대화에서 확정된 내용이다. 용어는 루트 [`GLOSSARY.md`](../../GLOSSARY.md)를 따르고, 되돌리기 어려운 결정의 배경은 [`docs/adr/`](../adr/)에 기록한다. 미확정 사항은 구현 요구사항으로 간주하지 않는다.

## 공유 범위와 문서 상태

- 2026-10-18 표와 후속 답변으로 아래 카드 70장(기본 2, 토큰 1, 일반 21, 고급 25, 희귀 19, 고대 2)과 전용 유물 5종(시작 1, 강화 시작 1, 일반 1, 고급 1, 희귀 1)을 구현 범위로 확정했다.
- 이후 보상 카드 풀을 확장할 수 있다. 컨셉별 장수 목표는 추가 카드의 확정 명세가 아니다.
- 아래 수치는 사용자가 정한 현재 구현값이며, 플레이를 거쳐 다시 조정할 수 있다.
- 기존 효과를 참조하는 부분은 실제 구현 시 게임 코드와 대조한다. 참조 대상의 세부 동작을 이 문서에서 확인했다고 간주하지 않는다.

## 플레이 방향과 카드 구성

- 전투 초반 템포는 주문이 지원하고, 전투 중 카드를 성장시켜 후반을 지배한다. 시작 덱은 개선으로 유산을 가공하는 플레이를 소개하며, 주문은 보상 카드로 확장한다.
- 주요 컨셉은 마법 주입·판금·활력·주문·수호이며, 각각 약 10장의 지원을 목표로 한다. 여러 컨셉을 연결하는 카드는 중복 집계한다.
- 미니 컨셉은 역작(Masterwork)·유산·강화·결투·화염·용맹이며, 각각 약 2~5장을 구상한다. 역작은 처음 구상한 '유물' 테마의 변경된 이름이다.
- 판금과 활력은 각각 Eternal Armor와 Regent의 Patter가 제공하는 기존 효과를 사용한다. 판금은 기존 문서의 철갑에서 이름을 바꿨다. ([ADR-0001](../adr/0001-reuse-base-game-effects.md))

## 수호와 시작 유물

- 기본 시작 유물 청동의 번견은 전투 시작 시 수호 5를 제공한다. 강화 시작 유물 쿠우는 청동의 번견을 교체하며, 전투 시작 시 수호 10과 내 턴 종료 시 남은 에너지가 있을 때 수호 5를 제공한다.
- 수호 N은 각 강철의 수호자에 누적되는 방어도를 N 높인다. 처음 생성된 카드는 방어도 N이며, 청동의 번견으로 시작할 때는 5다. 기본값 5를 별도로 더하지 않는다.
- 소멸하지 않은 수호 카드가 없으면 손에 생성한다. 생성 여부를 판단할 때 일시 복제본은 제외하고, 손패 초과는 기존 카드 이동 규칙을 따른다.
- 수호 카드의 이름은 강철의 수호자다. 1코스트·보존 스킬이며 강화하면 비용이 0이 된다. 사용하면 카드에 누적된 방어도를 얻고 버린 카드 더미로 이동한다.
- 소멸한 카드를 포함한 모든 일반 사본의 방어도가 함께 증가한다. 일시 복제본은 수치 증가에서 제외한다. 생성 시점이 다른 사본은 방어도가 다를 수 있다.
- 수호의 생성·성장·복사 규칙은 Forge를 따른다. 공통 수호값을 미러링하던 Q6 결정은 사용자 요청으로 롤백했다. ([ADR-0002](../adr/0002-guard-follows-forge.md))
- 역장 아가리는 소멸 더미를 포함해 전투에 있는 강철의 수호자의 누적 방어도 중 가장 높은 값을 기본 피해로 사용한다. 카드가 없으면 참조값은 0이다. 민첩 등 사용 시 방어도 보정은 참조값에 포함하지 않으며, 공격 보정은 기존 게임 규칙을 따른다.

## 인챈트와 강화

([ADR-0003](../adr/0003-combat-scoped-enchantments-and-legacy.md))

- 인챈트와 강화 부여는 기본적으로 해당 전투에서만 유지되며, 고대 카드 `천재의 영감`만 전투 종료 시 영구 개선을 수행한다.
- 일반 카드에는 인챈트를 하나만 부여할 수 있다. 이미 인챈트가 있는 카드는 추가 부여나 교체의 대상으로 선택할 수 없다.
- 유산은 이 제한을 받지 않는 고유 키워드다.
- 마법 주입은 별도 명시가 없다면 손에 있는 카드 중 하나를 선택해 인챈트를 부여한다. 다른 카드 더미를 대상으로 하는 효과는 개별 카드에 명시한다.
- 강화는 휴식에서 수행하는 기존 카드 강화와 같은 효과다. 이미 강화된 카드의 취급도 기존 규칙을 따른다.
- 유산에는 동일한 인챈트도 반복해서 부여할 수 있다. 수치가 있는 동일 인챈트는 유지 범위가 같을 때 합산해서 표시한다. 예를 들어 일시적 예리 3을 두 번 부여하면 일시적 예리 6으로 표시한다.
- 예리·숙련을 중심으로 기존 인챈트를 활용하며, 필요한 경우에만 추가 인챈트를 고려한다. 기민은 개별 카드에서 명시적으로 부여할 수 있다.

### 일시적 인챈트 표시와 유지 범위

- 일시적 인챈트는 카드 설명에서 기존 영구 인챈트와 다른 색으로 표시한다. 구체적인 색상은 미정이다.
- 같은 종류라도 영구 인챈트와 일시적 인챈트를 하나의 수치나 설명 항목으로 합치지 않는다.
- 예를 들어 영구 예리 3이 있는 유산에 개선 2를 적용하면 영구 예리 3과 일시적 예리 2를 별도 항목·색상으로 표시한다. 효과에는 둘 다 기여하며, 전투 종료 시 일시적 예리 2만 제거한다.
- 전투 한정 효과가 끝나도 기존 영구 인챈트·강화는 유지한다. 표시 분리는 일반 카드의 인챈트 제한을 완화하지 않는다.

## 시작 덱

- 타격 4장·수비 4장·고유 카드 2장의 총 10장 구성을 바탕으로 한다.
- 장인 컨셉을 드러내도록 고유 카드 한 장은 유산 키워드가 있는 공격 카드로 둔다.
- 유산 공격은 소멸하지 않는 단순한 공격 카드로, 반복해서 뽑고 인챈트를 쌓는 역할이다. 주문 테마는 붙이지 않는다.
- 다른 고유 카드 한 장은 방어도 제공과 마법 주입 효과를 함께 가진다.
- 유산 공격은 강화하면 피해가 증가하고 보존을 얻는다.

시작 고유 카드는 2026-10-17 표에 따라 다음과 같이 변경한다.

| 카드 | 비용·타입 | 기본 효과 | 강화 시 |
|---|---|---|---|
| 비행 글레이브 | 1·공격 | 피해 6. 유산. | 피해 8. 보존 추가. |
| 담금질 (가칭) | 1·스킬 | 방어도 5. 개선 2. | 방어도 유지. 개선 3. |

## 개선 키워드

- 공통 부여 동작은 '개선 N'으로 표기한다. 마법 주입은 테마, 개선은 구체적인 부여 동작이다.
- 개선 N: 손의 카드 1장을 선택한다. 공격이면 예리 N을, 그 외에는 숙련 N(사용 시 방어도 N 제공)을 이번 전투 동안 부여한다.
- 공격이면서 방어도를 제공하는 카드에도 예리를 부여한다.
- 기존 인챈트 제한을 따른다. 이미 인챈트가 있는 일반 카드는 선택할 수 없고, 유산에는 반복 부여할 수 있다.
- 유효한 대상이 없으면 개선만 불발하며, 카드의 다른 효과는 정상적으로 발동한다. 예를 들어 담금질은 이 경우에도 방어도 5를 제공한다.

## 주문

([ADR-0004](../adr/0004-spell-zero-energy-check.md))

- 주문은 카드 타입과 별개인 테마다.
- 추가 효과는 비용 지불 직후 남은 에너지가 0인지 판정하며, 에너지 환급은 판정 이후 처리한다.
- 다른 효과로 비용이 0이 되어도 같은 판정을 사용한다. 에너지 0에서 사용하면 발동하고, 에너지가 남아 있으면 발동하지 않는다.
- 추가 효과는 아래 카드별 명세를 따른다. 강철 집게의 주문 분류는 표기 실수였으므로 제거하며, 그 카드의 강화는 항상 실행한다.
- 주문 테마 자체에서는 비용 감소를 지원하지 않는다. 매 턴 한 번 정도 추가 효과를 얻기는 쉽지만, 주문만으로 덱을 구성하는 것이 유리해지지 않도록 설계한다.
- 0코스트 주문은 에너지 0에서 항상 발동하므로 요정 불빛(기본 소멸, 강화 시 소멸 제거)처럼 제한적으로만 둔다.

## 역작

([ADR-0005](../adr/0005-masterwork-repeats-effect-not-play.md))

- X코스트 카드 테마로, 소비한 에너지 X에 따라 카드 효과를 총 X회 실행한다. X=2이면 총 2회다.
- 공격 카드에 붙는 숙련처럼, 가능한 많은 인챈트가 반복 실행마다 효과를 발휘하도록 하는 것이 설계 목적이다.
- 여러 장의 카드를 사용하는 판정이 아니라, 한 카드의 효과를 여러 번 반복하는 판정이다.
- 활력은 모든 반복 공격에 적용하고 전체 실행이 끝난 뒤 소모한다. 기본 피해 4, X=3, 활력 2라면 피해 6을 3회 준다.
- X=0이면 반복 실행은 0회이며, 피해나 인챈트 효과도 실행하지 않는다.
- 반복 중 대상이 사망하면 남은 반복은 중단한다.
- 카드 본문과 숙련 같은 인챈트 효과를 반복마다 실행한다. 예를 들어 '역작, 피해 8, 숙련 3'인 카드를 X=3으로 사용하면, 대상이 생존하는 동안 피해 8을 3회 주고 방어도 3을 3회 얻는다.
- 그 외 개별 인챈트와의 세부 상호작용은 실제 카드 추가 시 확인한다.

## 결투와 용맹

- 결투는 대상에게 약화(`WeakPower`)와 취약(`VulnerablePower`)이 모두 없으면 추가 효과를 받는다. 그 외 효과나 몬스터 자체 기믹은 조건을 방해하지 않는다.
- 용맹은 대상에게 양수 힘 또는 방어도 중 하나라도 있으면 추가 효과를 받는다. 두 조건을 모두 충족해도 추가 효과는 한 번만 적용한다.
- 대부분 조건 충족 여부만 따지며, 수치에 비례하는 효과는 일부 카드에만 둔다. 이 경우 기준을 개별 카드에 명시한다.

## 화염

- 별도 전용 효과를 만들지 않고 Ironclad의 Flame Barrier에 붙는 기존 효과를 활용한다. ([ADR-0001](../adr/0001-reuse-base-game-effects.md))
- 화염 N은 다음 내 턴 시작까지 적의 공격을 받을 때마다 공격자에게 N 피해를 준다.
- 방어도로 피해를 전부 막아도 발동하며, 다단 공격은 타격마다 발동한다.
- 여러 번 얻으면 수치를 합산하고 다음 내 턴 시작에 모두 제거한다.

- 대가의 무기의 가한 피해 계산은 기존 Fisticuffs와 동일하게 방어도로 막힌 피해와 초과 피해를 포함한다.
- 마법 땜질과 경계 재련은 이미 강화됐거나 인챈트가 있는 카드도 가져올 수 있다. 불가능한 강화·개선 부분만 불발한다.
- 요정의 청동(구 고철 조각)은 반복마다 개선 대상을 다시 고른다. 일반 카드는 첫 개선 뒤 다시 선택할 수 없고, 유산은 같은 카드를 반복 선택할 수 있다. 자기 인챈트의 사용 효과도 반복마다 실행하며 X=0이면 실행하지 않는다.
- 오래된 끌은 기존 인챈트 제한을 따르며, 이미 보존이 있는 카드는 선택 대상에서 제외한다.
- 뜨임은 손의 아무 카드나 선택해 버릴 수 있고, 버린 카드 중 개선 가능한 카드만 개선한다.
- 망치질은 뽑은 시점에 이미 강화되어 있던 카드마다 활력 3을 얻고, 강화되지 않았던 카드는 이번 효과로 강화한다. 대장간의 열기도 뽑는 시점에 이미 강화되어 있던 카드에만 발동한다.
- 회수할 카드가 없으면 새로 만들지 않는다. 손에 있는 카드는 그대로 두며 손패 초과 처리는 기존 카드 이동 규칙을 따른다. 자가 수리는 회수 전에 수행하는 수호의 생성 규칙은 그대로 적용한다.
- 비행 글레이브와 요르디나 막 들레헴의 보존, 첫번째 결투·마상 창시합·고브누의 제련·요정 장인·아그드리드의 모루의 선천성은 강화 시에 얻는다. 아그드리드의 모루는 강화 시 선천성과 함께 개선 수치도 3에서 4로 증가한다.
- 고브누의 제련·영웅의 갑주·원초의 형상·낡은 작업소·요정 장인은 실제로 강화 또는 개선이 적용된 카드마다 발동한다. 마법 땜질·경계 재련·아그드리드의 모루처럼 한 카드에 강화와 개선이 모두 적용되면 낡은 작업소는 각각에 대해 발동한다.
- 불꽃의 티끌이 동반 개선될 때도 실제 개선으로 취급되어 낡은 작업소·영웅의 갑주·원초의 형상을 발동시키되, 다른 불꽃의 티끌을 다시 연쇄 발동시키거나 고브누의 제련 증가분을 중복 가산하지는 않는다.
